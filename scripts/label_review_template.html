Label review

How to review

For each conversation, judge the labels (not a model answer) against the 40-paper proxy corpus. Mark each check:

  • Category names: every category the turns name or assume exists as named, and a "missing category" question names one that really is missing.
  • Exact counts: every expected count is right for the loaded corpus. A semantic topic count is a classified subset; check the listed papers are about the topic.
  • Paper/page facts: every named paper exists, and each page and quote supports the turn. matches means it matches proxy_starter.json; you still judge whether it supports the task.
  • Supported & unambiguous: the draft flag is right. True means one clear correct behaviour; true conversations form the 90% completion denominator.

Yes or N/A passes; No means fix the label in the set JSON first, then mark the conversation Corrected. Then set the status. Your work saves in this browser; export when you're done (or to keep a backup).
