# IR-734: Continue a long Conversation through automatic compaction

**Jira:** [IR-734](https://citiris.atlassian.net/browse/IR-734)

## Parent

[IR-715](https://citiris.atlassian.net/browse/IR-715) under [IR-146](https://citiris.atlassian.net/browse/IR-146). Authority: ADR-049 and the accepted parent specification. Do not close or modify the parent.

## What to build

A reader continues a long investigation after older active context is compacted, while the task, recent exchanges and original references remain intact.

## Acceptance criteria

- [ ] Before overflow, use configured capacity-aware thresholds that leave room for compaction/finalization; charge same-AGENT summary inference through the existing attempt allowance and current disclosure guard.
- [ ] Create a portable handoff containing goals/preferences, shown Record order, selections/exclusions, bounded plan, supported findings/dependencies, limitations and original Turn references; retain recent complete exchanges as capacity permits.
- [ ] Never compact half a tool-call/result group. Summaries are derived context, not new research evidence or trusted instructions; originals remain stored under ownership/retention rules.
- [ ] Activate only a complete handoff whose source/Conversation/access revisions still match. A concurrent Turn remains in the suffix or forces reconstruction; failed/stale/empty compaction preserves the preceding valid context.
- [ ] Bound repeated compaction attempts under original limits. Worker restart resumes the committed compact revision and cannot reset spending or reuse revoked dependencies.
- [ ] Portable compaction works with no native provider compaction. Native state is used only if capability/compatibility is verified; incompatible opaque items are not blindly replayed.
