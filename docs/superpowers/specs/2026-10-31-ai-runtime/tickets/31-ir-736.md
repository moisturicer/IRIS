## What to build

A reader completes a long-paper investigation across several compactions and safely continues when optional native continuation is incompatible.

## Acceptance criteria

- [ ] Exercise middle/late/contradictory facts from full Manuscripts across repeated automatic/manual compactions, exact-detail recovery and reopened history.
- [ ] Preserve goals, order, exclusions and original evidence bindings; evicted text is not represented as still model-visible and coverage gaps remain explicit.
- [ ] Change a prefix/tool schema or adapter capability so opaque state is incompatible: reconstruct supported portable context from permitted originals or stop safely, without forwarding stale artifacts.
- [ ] An explicit supported model change requires reauthorization/reconstruction and verified new capacity; an in-flight run never silently switches to a smaller/incompatible model.
- [ ] Record complete serialized-request fit, original allowance, atomic revision and citation checks in IR-605-compatible deterministic cases; absence of native support still permits the portable path.
