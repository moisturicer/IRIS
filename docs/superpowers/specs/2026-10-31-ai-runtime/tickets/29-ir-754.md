# IR-754: Compact a Conversation from the reader screen

**Jira:** [IR-754](https://citiris.atlassian.net/browse/IR-754)

## Parent

[IR-715](https://citiris.atlassian.net/browse/IR-715) under [IR-146](https://citiris.atlassian.net/browse/IR-146). Authority: ADR-049 and the accepted parent specification. Do not close or modify the parent.

## What to build

A reader deliberately compacts an owned Conversation, sees what happened and continues with original history still available.

## Acceptance criteria

- [ ] An accessible Compact conversation action invokes the same authorized bounded mechanism as automatic compaction; it does not create a second summarizer or bypass spending/disclosure.
- [ ] Manual work has an explicit bounded run identity/allowance or uses the active run only where the revision contract permits; it never silently extends an active investigation's budget.
- [ ] Handle active-run conflicts, duplicate clicks, Stop, expired authorization, failure and stale revisions with one coherent outcome and preserved prior valid context.
- [ ] Live/reconnected/reopened UI distinguishes compacting, compacted, unavailable and estimated capacity states. Original history is not described as deleted; detail recovery remains possible while permitted.
- [ ] Keyboard/screen-reader and narrow-layout behavior works in Ask IRIS and Paper Chat; the action never widens Record scope or renders raw/opaque/private state.

## Independent demonstration

Use the reader action on an owned Conversation, reconnect during compaction, double-click the action and inject failure; then ask for an older exact detail.

## Scope boundary
