IRIS: four identity directions

Research · Review · Discovery

Three directions from the concept sheet, redrawn as working vector marks, and a fourth added here. Each one ships a mark, lockups, a loading state, a search icon, an Ask IRIS icon and a reversed banner in the institution's maroon. Gold is decoration only: it never carries text or status.

01Folio Ribbon

An open folio whose two leaves turn like a ribbon around a serif I. It reads as a bound volume being opened, which is the system's own north star.

What each direction ships

  • mark.svg and mark-reversed.svg: the cut-outs are transparent, so either works on any ground.
  • lockup-stacked.svg, lockup-horizontal.svg and banner-reversed.svg.
  • loading.svg: the mark in motion. It stops when the reader asks for reduced motion.
  • icon-search.svg and icon-ask-iris.svg.

Brand rules kept

Maroon #6B0F12 is the only brand colour. Gold #C9973A appears only as ornament (about 2.8:1 on white, so never text or status). The wordmark is EB Garamond 600, converted to outlines so no file needs a font installed.

Not adopted yet

These are proposals. Nothing in the application uses them. Adopting one means replacing the mark in the sidebar, sign-in panel and favicon, and recording it in docs/ui-ux/01-design-system.md.
