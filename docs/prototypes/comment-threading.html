Design notes for review
  • Two levels, like Facebook. Top-level comments and their replies. A reply to a reply stays in the same thread and shows an @name link to the comment it answers.
  • Thread line. A line runs from the parent's avatar down to each reply, so the conversation reads as one unit.
  • Replies collapse. A thread with more than two replies starts collapsed behind "View N replies".
  • Bubble plus quiet actions. Reply stays visible under each comment. Edit, Delete and Report move into a "..." menu.
  • Inline reply and edit. No jump back to the top of the page. Ctrl or Cmd + Enter posts, Esc cancels, Enter adds a line.
  • Relative time (5m, 2h, 3d) with the full date on hover and for screen readers.
  • Deleted comment with replies stays as a placeholder so the thread keeps its context.
