# IR-1279: A draft's row has Continue draft and a trash can under Updated

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** on a draft's row in My Library, *Continue draft* and a trash can for deleting it are buttons again, under *Updated <date>*, level with the authors and Adviser line and the sentence saying what the draft waits on. Only Delete asks a question: one confirmation. Requested by Hermoine Zozobrado on 2026-11-23. No FR- id.

**Design:** this supersedes [IR-1261](IR-1261.md)'s "⋯" menu for drafts and brings back [IR-1256](IR-1256.md)'s red trash can and *Continue draft*. IR-1261's row link stays: a click anywhere on the row still opens it. A draft is deleted only after one confirmation, so [ADR-009](../../adr/009-authorization-model.md) decision 6 still holds.

## What changed

- `SubmissionRow.tsx`: a draft's right column holds, under *Updated*, *Continue draft* (`PILL_PRIMARY`, to the same Publish link as the row) and, where the list can drop the row, the trash can. Above the row's link, so a press acts on the button. On a narrow screen the pair wraps onto its own line under the date. IR-1261's corner-pinned menu and the padding kept for it are gone.
- `DeleteDraft.tsx`: IR-1256's red trash can again (named "Delete draft “<title>”", tooltip *Delete draft*), opening the same `ConfirmDialog`.
- Rows that aren't drafts are unchanged.
- Smoke dialog scan (`e2e/smoke/support/dialogs.ts`): *delete a draft* presses the trash can again.
