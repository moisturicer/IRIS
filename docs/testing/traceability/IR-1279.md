# IR-1279: A draft's row has a trash can under Updated

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** on a draft's row in My Library, deleting is a red trash can again, rightmost under *Updated <date>*, level with the authors and Adviser line. It asks one question before deleting. There is no *Continue draft* button: clicking the row already continues the draft. Requested by Hermoine Zozobrado on 2026-11-23. No FR- id.

**Design:** this supersedes [IR-1261](IR-1261.md)'s "⋯" menu for drafts and brings back [IR-1256](IR-1256.md)'s red trash can. IR-1261's row link stays, and so does its removal of *Continue draft*. A draft is deleted only after one confirmation, so [ADR-009](../../adr/009-authorization-model.md) decision 6 still holds.

## What changed

- `SubmissionRow.tsx`: where the list can drop the row, a draft's right column holds the trash can under *Updated*, right-aligned, above the row's link so a press deletes rather than opens. On a narrow screen it sits at the right end of the badge-and-date line. IR-1261's corner-pinned menu and the padding kept for it are gone.
- `DeleteDraft.tsx`: IR-1256's red trash can again (named "Delete draft “<title>”", tooltip *Delete draft*), opening the same `ConfirmDialog`.
- Rows that aren't drafts are unchanged.
- Smoke dialog scan (`e2e/smoke/support/dialogs.ts`): *delete a draft* presses the trash can again.
