## IR-668 — Production /django-admin/ is closed except to allowlisted networks (ASVS 4.3.1)

`frontend/nginx.conf` answers 403 on `/django-admin/` unless the client is in `DJANGO_ADMIN_ALLOWED_NETWORKS`, which `docker-entrypoint.d/40-iris-django-admin.sh` turns into nginx config at start. No allowlist allows nobody. The client address follows `TRUSTED_PROXY_COUNT`, as IR-656's does.

`scripts/check_django_admin_allowlist.sh`, in CI's Docker Compose job, runs the real nginx and proves the default deny, a listed client, an unlisted one, forged `X-Forwarded-For` values and refused bad settings.

**The allowlist now guards Django's admin.** Before IR-782 the admin was at `/admin/`, which nginx left open, so the 403 guarded a path Django did not serve. [IR-782](IR-782.md) moved the admin to `/django-admin/` and removed the open `/admin/` proxy.
