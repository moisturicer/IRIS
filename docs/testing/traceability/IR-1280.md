## IR-1280 — An answer delivered after failed repairs keeps its Markdown

**Basis and scope.** IR-1280 (bug). Observed 2026-11-23 in Paper Chat: an answer carrying "(the sources read do not establish this)" reached the reader as one block, its sections ("Participants and timing:", "Questionnaire:") run together. No ADR change: this restores what IR-729/IR-995 meant to deliver, the draft whole.

**Cause.** `ai/agent/assurance.py::qualified()` split the draft on `\n+` and rejoined with one `\n`, dropping every blank line; lines separated by a single newline are one Markdown paragraph. It also stripped each line, losing list nesting. `bindable()` collapsed every run of spaces, flattening nested lists and code anywhere in an advisory or flagged answer. The renderer (`CitationText`, react-markdown + GFM) was rendering what it was given.

**What exists now.**
- `qualified()` walks the draft line by line (`_markdown_lines`): blank lines stay (at most one in a row), each line keeps its indentation, fenced code is passed through untouched, and only sentences are checked and qualified. A table row's mark goes inside its last cell, since after the closing pipe GFM would drop it as a cell past the header.
- `bindable()` removes unbindable citations line by line and closes only the gaps they leave inside a line; a line's leading indentation and fenced code are never changed.

**Tests.**
- `backend/apps/ai/tests/test_ai_runtime_answer_markdown_contract.py`: a draft with bold-led paragraphs, a nested list, a fenced code block and a table, failing its checks through every repair, is delivered with all of them intact and its unsupported sentence and row marked; `bindable()` keeps a nested list's indentation and code spacing while closing a removed citation's gap. Both failed before the fix (blank lines and indentation lost).
- Unchanged and passing: the delivery tests in `test_ai_runtime_agent_loop_contract.py`, `_ir995_contract`, `_partial_outage_contract`, `_turn_recovery_contract`.

**Runs** (2026-11-23, Windows 11). Every `test_ai_runtime_*_contract.py` and `test_ir11*_contract.py`: 414 passed. flake8 (as CI) and over `ai/agent`: clean. CI runs the full suite on the pull request.

**Not done here.**
- Answers already stored flattened stay as they are: their original line breaks were not kept.
- Why that answer failed its checks (quoted questionnaire labels read as titles, figures not in the cited passages) is a separate question.
