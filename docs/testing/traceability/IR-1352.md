# IR-1352: Tighter sign-in and register spacing, and no Help on register

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** tighten the space between fields on sign in and register, and remove *Help* from register as IR-1281 did on sign in. Requested by Lee Jasmin Adolfo on 2026-11-28. No FR- id.

**Design:** no ADR change.

## What changed

- **Spacing.** Each field keeps a 20px empty line for its error message (`reserveErrorSpace`, IR-1303), and the form's `gap-5` was added on top of it. Both forms now use `gap-3`, so the empty line does most of the spacing.
  - `LoginForm.tsx`: `gap-5` → `gap-3`; the "Keep me signed in" row is `-mt-3` instead of `-mt-1`, which takes back the padding its 44px targets add above the text; the Sign in button has `mt-2`.
  - `SignupPage.tsx`: the step column and the first/last name pair use `gap-3`; the Continue/Register buttons have `mt-2`.
  - The 44px targets and the reserved error lines are unchanged, so an error still moves nothing.
- **Help.** `SignupPage.tsx` no longer passes `help`. No screen used it after that, so `EntryFrame` loses the `help` prop and its Help dialog. The footer's Data privacy and Terms are unchanged. This replaces IR-1281's "Register keeps its Help".
