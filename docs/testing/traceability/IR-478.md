## IR-478

**Requirement:** **RDCO grants and removes office coordinators on the Users page; demo coordinators** — ADR-032 §4, after IR-415; touches FR-M5-01 (stable label only)

**Design:** [ADR-032 §4](../../adr/032-adviser-first-review-and-office-reviewer-pools.md) · [ui-ux/02](../../ui-ux/02-information-architecture.md) §5 and [03](../../ui-ux/03-navigation.md), amended 2026-10-29 · design settled with the project lead 2026-10-29 (grilling: RDCO is the granter; any RDCO account grants as built, narrowing it proposed separately) · Jira IR-478

**Implementation:** `/admin/users` returns for RDCO (`lib/access.ts` `users`, Administration), reversing IR-160 because the Django admin never registered `User`. `UserListPage`: a *Coordinator* badge on office members whose flag is set; *Make coordinator* / *Remove coordinator* on ITSO, IERC, KTTO and RDCO rows only, each through `ConfirmDialog` stating its consequence, calling `PATCH /users/<id>/coordinator/` (`accountsApi.setCoordinator`) and updating the row from the response, a refusal shown in the dialog with the row unchanged; *Change role* warns a coordinator loses the flag (`User.assign_role` drops it on every save), and its select is labelled and reads `ALL_ROLES`. `UserListView` names `search_fields` (the search box was ignored) and `UserSerializer` sends read-only `is_active` (every row read Inactive). The `DataTable` pager buttons are named. `seed_demo` adds `itso.`, `ierc.`, `ktto.` and `rdco.coordinator@cit.edu` with the flag, and seeds the plain `<role>@cit.edu` office logins without it

**Test:** `features/accounts/UserListPage.test.tsx` (badge, who is offered the action, both dialogs, cancel, refusals, the role-change warning, axe) · `lib/access.test.ts` (Users is RDCO only, in the Administration list) · `apps/accounts/tests.py::UserListTests` · `apps/records/test_seed_demo.py::SeedDemoCoordinatorTests`

**Evidence:** Run locally 2026-10-29: `UserListPage.test.tsx` and `access.test.ts` (39 passed), mutation-checked by breaking the office gate and the warning (2 failed as expected); `tsc --noEmit` clean; eslint clean bar two existing warnings; flake8 clean; the backend tests collect. **The backend tests were not run locally** (the local Postgres was unreachable); left to CI on the PR
