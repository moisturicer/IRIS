## IR-353

**Requirement:** **Find in this paper: search the open PDF's text and jump to each match** — a reader feature on IR-335's PDF.js reader

**Design:** [ADR-031](../../adr/031-pdf-citation-overlay.md); Jira IR-353

**Implementation:** `lib/pdf.ts` gains `pageText` (pdf.js `getTextContent`, cached per page and shared with the text layer, each run carrying its vertical band as fractions of the page) and `renderTextLayer` (pdf.js `TextLayer`, not `PDFViewer`/`PDFFindController`, which would have meant replacing the reader). Every page now draws a text layer between its canvas and `CitationOverlay`, so the paper's text is selectable and a citation's highlight still draws above find's; `index.css` carries only the `.textLayer` rules the layer needs from pdf.js's viewer stylesheet. `findInPaper.ts` (pure) matches case-insensitively with whitespace collapsed and a line's end read as a space, so a phrase that wraps is found; `findHighlights.ts` wraps each match in a `<mark>` inside pdf.js's span, which keeps it on the words at any zoom. `usePaperFind.ts` extracts text page by page in the browser (never the backend's chunk text, which exists only for indexed records — none yet, IR-250), so typing never waits and the count fills in; a new query goes to its first match from where find last was or from the page being read. `PaperFind.tsx` is a `role=search` row inside the reader's toolbar with a labelled searchbox, an "n of m" `role=status`, previous/next and close; Ctrl/Cmd+F with the reader focused opens it, Enter / Shift+Enter step, Esc clears the highlights and returns focus. A match lands through IR-354's landing (`land`, now shared by citations and find), instantly, and only when `readerGeometry.regionInView` says it is out of view. A paper with no text says "This paper has no searchable text" and offers nothing to step through

**Test:** `findInPaper.test.ts` (12, pure: case, every page, no overlap, across runs and line ends, whitespace, match band, pages not yet extracted, where find starts, per-page hits, no-text), `findHighlights.test.ts` (3: marks without changing a span's text, a match across runs, clearing), `readerGeometry.test.ts` (`regionInView`), `PaperPdfReader.test.tsx` (15 new, `lib/pdf` mocked with a fake text layer: toolbar control distinct from the header search, Ctrl and Cmd+F, count across pages, Enter/Shift+Enter wrapping, the prev/next controls, a phrase over a line's end, no matches, no searchable text, typing before extraction finishes, landing below header + toolbar, not moving for a match in view, Esc clearing and returning focus to the toggle or the paper, text layer with the citation overlay above it, axe clean with find open)
