# IR-766

[Back to the matrix](../TRACEABILITY.md)

**Saved Calls appear in My Library and under the board's Saved filter.** Built to [ADR-050](../../adr/050-calls-for-papers-and-rdco-confirmation.md) decision 13 and its amendment of 2026-11-16 (IR-649: only a confirmed Call is saved; one sent back or rejected is unavailable, for everyone). The server side is IR-649's. Written 2026-11-16, on top of IR-765 (PR #847) and IR-764 (PR #846), which it needs. PR [#848](https://github.com/moisturicer/IRIS/pull/848).

## What changed

- **Saves follow the account** (`store/savedCalls.store.ts`, over `GET /opportunities/saved/` and `PUT`/`DELETE /opportunities/<id>/save/`), with the paper library's behaviour (IR-566, `store/library.store.ts`):
  - cleared on every session change, so the next person on a shared PC starts empty;
  - an answer that lands after the session changed is dropped;
  - only the newest write to a Call decides;
  - a save or removal shows at once, and on failure it rolls back and a toast says what failed, with Try again; a Try again from before the session changed does nothing;
  - a read that timed out is "interrupted" (IR-906), shown as such with Retry.
  - Nothing touches the browser's storage.
- **My Library has a Saved calls tab** (`features/opportunities/SavedCallsSection.tsx`, `?section=calls`), apart from Saved papers, for every reader.
  - Each Call shows both tags, Over included (`CallTags` with `allEvents`), as it reads everywhere (`CallDetails`), with its paper deadline, **View call** and **Remove**.
  - A Call stays until the reader removes it or RDCO deletes it.
  - One sent back to RDCO or rejected is listed as "Unavailable call", with nothing more about it, and can be removed.
- **The board's Saved filter** shows the saved Calls still on the board and counts only those. Its Save control writes to the account.
  - The board reads the account's saves afresh with each load, so a save made on another device shows.
  - Until that list has loaded, or if it can't, the board shows the server's own `is_saved` on each Call, so a failed read never shows every bookmark as unsaved.
- **Order:** saved Calls are newest first, as the server orders them, an unavailable one in its place (ADR-050 decision 13); a new save goes first.
- **Old browser saves are dropped:** `lib/opportunityLibrary.ts` is deleted, and `iris_saved_opportunities` joins the old library keys `clearOldBrowserLibrary` deletes on every sign-in, sign-out and session end (IR-579), never read or imported.
- **Wording:** "kept in this browser only" is gone from the board, its save control, the empty Saved filter and the load error. The Help page says saved Calls follow the account and stay in My Library.
- **Shared:** the two tags are one component (`CallTags`), used by the board and My Library.
- **Smoke tier:** the board's smoke screen mocks the saved Calls it now reads.
