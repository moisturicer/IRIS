# IR-1081: a reload that cannot restore the session says so on sign-in

**Requirements:** none. This is a UI defect found in the IR-1071 audit (FB-01), so the matrix has no row for it.

## Reproduction

Done by reading the code and pinning it with tests, not in a browser. Steps for a real browser are at the end.

On a reload, `AuthBootstrap` calls `hydrateAuth`, which exchanges the refresh token kept in `sessionStorage`. When that fails for any reason (the token was rotated or revoked, the server is down, a request is blocked, or the profile request fails after a good refresh), it calls `logout()`. The route guard then sees no access token, which looks the same as never having signed in, and sends the person to `/login` with the destination but **no reason**. The login screen shows no banner. That is FB-01, and a blocked request in the audit browser was enough to trigger it.

The other paths already explained themselves: an expired access token in the guard, a failed refresh in `api/client.ts` and the idle timeout all send `reason=session_expired`.

## What changed

- **`auth.store.ts`:** `hydrateAuth` records `sessionLost` (with the server's `code` when it gave one) when a stored session could not be restored. A sign-in clears it. A tab with no stored token never sets it.
- **`ProtectedRoute.tsx`:** with `sessionLost` set and no token, it redirects with `reason: session_expired`, the server's code if the login screen knows it (else `session_lost`) and the page asked for.
- **`authSession.ts`:** `session_lost` has its own message, "Your session ended. Sign in to continue where you were." It is kept out of `SESSION_END_MESSAGES`, which stays exactly the server's five codes.
- **`LoginPage.tsx`:** reads the code from router state as well as the address. The page is returned to after sign-in by the existing `from` handling (IR-236).

**Not changed:** a failed reload still clears the stored refresh token, even when the cause was a network error, so a blip ends the session. Whether to keep it for a network failure is a separate decision.
