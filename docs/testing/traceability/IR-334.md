## IR-334

**Requirement:** **Citation regions reach the wire, the manuscript is servable again, generation actually streams, and the AI Overview is generated once** — extends FR-M3-01/FR-M3-02 (stable labels only, per the frozen-SRS rule)

**Design:** [ADR-031](../../adr/031-pdf-citation-overlay.md)

**Implementation:** `apps/ai/regions.py` (new) converts a chunk's stored `bboxes` (PDF points) into fractions of the page against `ChunkSet.page_sizes`, dropping a degenerate rectangle, one on a page of unrecorded size, or a malformed one — each would otherwise draw a box in the wrong place, which is worse than none; the page still travels separately as `page`. `RetrievedChunk` and `Citation` both gain `regions`; `two_stage.py` and `degraded.py` populate them, `reranking.py` now rebuilds a reordered chunk with `dataclasses.replace` instead of naming every field, so a field added to `RetrievedChunk` cannot silently stop surviving a reorder the way `regions` would have. `apps/ai/presentation.py` puts `regions` on every passage and citation; `apps/ai/conversations.py::_resolve_citation` re-resolves them from the live chunk on every replay, the same re-resolution ADR-019 already does for the quote. **The manuscript link has been dead since IR-152** — `RecordSerializer` echoed `abstract_file` as a `/media/...` path, and nothing has served that path in any environment since IR-152 removed both the nginx block and Django's `DEBUG` `static()` route. `RecordViewSet.manuscript` (`GET /records/<id>/manuscript/`) serves it inline through `visible_to(user)`, reusing `download_service.resolve_record_download_file`; `abstract_file` on the detail serializer now reports that endpoint (or `null`, via the new `has_record_download_file` cheap-existence check) instead of the stored path, and `files[].url` points at the existing authorized download view instead of `f.file.url` for the same reason. **Streaming now actually streams**: `RetryingLLMProvider`, `CircuitBreakingLLMProvider` and `FallbackLLMProvider` gain `stream()` — IR-321 wrapped every configured provider in decorators implementing only `generate()`, so against the real model `LLMProvider.stream()`'s buffering default ran and `/ai/ask/stream/` delivered the whole answer as one `text_delta`, exactly the limitation `ChatStreamView`'s docstring recorded. The rule the three new implementations share: retry and failover happen only **before** the first delta (`_open_stream`/`_yield_from_opened` in `resilience/llm.py`) — once a token has reached the reader, restarting the call would repeat or duplicate text already on their screen, so a failure after first output propagates instead. `GroundedAnswerService` also now degrades a refused (`CircuitOpen`) call the same way it degrades a failed one, on both the synchronous and streaming paths. **The AI Overview is generated once and cached**: `PaperAiOverview` used to fire `/ai/ask/` from a `useEffect` on every mount, an unscoped corpus-wide vendor call for an answer that cannot change. New `RecordOverview` model (migration `0014`, replacing the field-less `DocumentSummary` placeholder from migration 0001 that no code path ever wrote to — the same move IR-89 F made for `DocumentChunk`) keyed one-to-one on the record, storing the text, citations, degradation flag, model id and the active `ChunkSet.content_hash` it was generated against. `apps/ai/overview.py::overview_for` returns the cached row when `content_hash` and `prompt_version` still match, regenerates through `composition_root().answer_service(record=record)` — scoped retrieval, not corpus-wide — on a miss or a stale hash, and never caches an `unavailable` state, so the next view retries once the vendor is back. `GET /api/v1/ai/records/<id>/overview/` (`RecordOverviewView`) is the endpoint, resolved through `visible_to(user)` like every other record read

**Test:** `apps/ai/tests/test_regions.py` (13, pure — normalization, clamping-not-dropping for coordinates a few points past the trim edge, and the five reasons a rectangle is withheld: degenerate, zero-area unflagged, inverted, unknown page size, zero page width), `apps/ai/tests/test_citation_regions_http.py` (4, DB — a citation and a search result each carrying the normalized region of its chunk, an empty list rather than an error when nothing was recovered, and a replayed Conversation Turn re-resolving regions exactly as it re-resolves quotes), `apps/records/test_manuscript.py` (8, DB, API seam — a permitted reader gets the PDF inline with `Accept-Ranges`, a reader without access gets 404 not 403, anonymous gets 401, a record with no file gets 404, an audit event is recorded, and `abstract_file` on the detail payload is the endpoint URL or `null`, never a `/media/` path), `apps/ai/resilience/tests/test_llm_streaming.py` (17, pure — every one of `RetryingLLMProvider`/`CircuitBreakingLLMProvider`/`FallbackLLMProvider`/the composed stack passing N scripted deltas through as N deltas rather than one; a transient failure *before* any delta retried, the identical failure *after* one not retried and not failed-over; a circuit that opened before any delta staying open, one that opened after a delta not counting against the breaker; a non-switchable kind — `auth` — never tried against the next configured provider), `apps/ai/tests/test_overview_http.py` (8, DB — two reads of the same record producing exactly one vendor call, asserted on `ScriptedLLM.calls`; a re-chunk invalidating the cached row and forcing exactly one more call; an unavailable model never persisted and retried on the next view; a record with no chunk set reporting `not_indexed`; a reader without access getting 404)

**Evidence:** `apps/ai apps/records` green, full backend suite green, no new failures against the pre-existing baseline (2026-09-23)

**Status:** **IMPLEMENTED** — the PDF.js reader that draws these regions, and the frontend overview cache consumer, landed as IR-335 (below).
