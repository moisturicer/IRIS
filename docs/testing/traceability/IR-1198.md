## IR-1198

**Requirement:** The diagonal mark on a downloaded copy and over the reader's pages reads "PROPERTY OF / CIT-U / DO NOT DISTRIBUTE" on three centred lines, in the same style as before, and still adds no text to the copy

**Design:** Jira IR-1198; ADR-048, Amendment 2026-11-17

**Implementation:** `backend/apps/records/watermark.py`: `MARK_LINES` and `MARK_GLYPHS` (each letter as stroked lines and elliptical arcs, one unit tall) drawn as one path by `_mark_lines`, centred, the longest line as wide as the page's short side. `frontend/src/features/records/paper-view/ReaderWatermark.tsx` mirrors the same table as SVG path data. Stroke, gap, grey, opacity, angle, flat ends and miter joins are unchanged

**Test:**

- `backend/apps/records/test_download_watermark.py`: `MarkWordingTests` (three lines, a shape for every letter, line widths 11.6 / 4.5 / 16.6); `test_the_mark_adds_no_text_to_the_copy` now also checks that neither "PROPERTY" nor "DISTRIBUTE" is in the copy's text.
- `frontend/src/features/records/paper-view/ReaderWatermark.test.ts`: the same wording and the same three line widths, so the two marks stay one shape.

**Evidence:**

- 2026-11-17, locally: `MarkWordingTests` pass (2 tests; the database-backed tests in the file run in CI, since local Postgres has no pgvector). `flake8` clean on both files.
- 2026-11-17, locally: `vitest run src/features/records/paper-view/` passes (55 files, 963 tests); `tsc --noEmit` and `eslint` clean.
- 2026-11-17, local renders (not the live site): the download overlay on a Letter page, through pypdfium2, and the reader's SVG, through headless Edge, both show the three lines in the same shapes; text extracted from the marked page contains no "PROPERTY".
