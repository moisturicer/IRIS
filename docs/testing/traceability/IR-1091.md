# IR-1091: Workflow analytics: the method in a disclosure and numbers aligned for comparison

[Back to the matrix](../TRACEABILITY.md)

**Requirements:** no FR- id. Epic IR-920 (S2 Epic: Frontend UI/UX Redesign). Audit finding LAY-05 ([`frontend_ui_audit_spec.md`](../../frontend_ui_audit_spec.md) Appendix A, IR-1071). Counting rules stay with [ADR-043](../../adr/043-review-turnaround-reminders-and-escalation.md).

## What changed

- **The page opens on the figures.** The paragraph under each heading (how overdue is counted, that time in stage is elapsed time and how many records a median needs, that throughput counts office visits, that preserved clearances are not a time saving, and that times are Asia/Manila with weeks from Monday) moved, word for word, into one **"How these numbers are counted"** disclosure. It is a button with `aria-expanded` and, once opened, a named region; it is closed by default and its body is not rendered until opened. It sits under the filters and the one-line note on when the log starts, which stays visible because work before that date is absent from the figures, not zero.
- **Numeric columns are right-aligned in tabular figures** in all four tables (Open now, Time in stage, Records entering and leaving, New versions and preserved clearances), headers and cells alike. Label columns (Office, Record type, Week of, Policy) stay left. A "Too few records (3 of 5)" cell is right-aligned with the figures it stands in for.
- **No metric was added or recomputed.** Every figure is still the server's; no wording of a definition was changed.

## Tests

- `frontend/src/features/review/ReviewAnalyticsPage.test.tsx`: the disclosure is found by role and name, is `aria-expanded="false"` on load, renders none of the method text until opened and is the only such control; opening it shows each definition in a named region and closing it removes them; every numeric column header and cell in the four tables has `text-right` and `tabular-nums` and each table's label column does not. The existing test that read the "not hands-on effort" sentence now opens the disclosure first, since the sentence is no longer on the page until then (changed deliberately; its assertion is the same).

## Evidence

- Run locally 2026-11-14: `ReviewAnalyticsPage.test.tsx` 15 of 15 passed; `tsc --noEmit` clean; eslint on `src/features/review` clean. `npm run test:changed` result is recorded in the PR. The full suite is left to CI.
- **Not checked:** the page in a browser against a real API, and a screen reader on the disclosure.
- **Decision:** the disclosure is a button and region rather than a native `<details>`, so closed means not rendered and its state is exposed as `aria-expanded`. The log-start note was kept visible rather than folded into the disclosure.
