# IR-1038: The shared UI primitives take their text size from the type roles

**Requirement:** `docs/frontend_redesign_spec.md` section 4.12 (type scale); IR-452 (named type scale); `docs/ui-ux/01-design-system.md` section 1 "Type" (the 14 px mapping).

The eleven shared primitives (`Button`, `Input`, `Select`, `Card`, `Modal`, `Badge`, `Toast`, `FieldError`, `fieldClasses.ts`, `ConfirmDialog`, `DataTable`) use `text-label`, `text-small`, `text-body` and `text-heading` instead of `text-[Npx]`: 12 px to `label`, 13 px to `small`, 14 and 15 px to `body`, 16 px to `heading`. Their entries are removed from `src/test/fontSizeAllowance.ts`, so the IR-1037 guard now fails if an arbitrary size returns to them.

Executed evidence (2026-11-14):

- `src/test/fontSize.test.ts` 9 / 9 with the eleven entries removed.
- `tsc --noEmit` clean.
- Layout, real components in a throwaway page (not committed), before to after. No horizontal scroll and no clipped button label at 360 or 1280 px, before or after.

| Measure | 1280 px before | 1280 px after | 360 px before | 360 px after |
|---|---|---|---|---|
| Input and select height | 38.6 | 41.6 | 38.6 | 41.6 |
| Table row height | 45.4 | 48.4 | 87.4 | 96.4 |
| Dialog height | 202.6 | 205.6 | 233.6 | 233.6 |
| "Save changes" button width | 125.8 | 132.5 | 125.8 | 132.5 |
| "Delete request" button width | 129.6 | 136.6 | 129.6 | 136.6 |

Open conflict, recorded not settled: the IR-1072 amendment (D1, decided 2026-11-14) gives form fields and page buttons a 14/20 `control` step, built by IR-1074. IR-1038 (decided 2026-11-12) maps 14 px to `text-body` and adds no role. The owner chose to follow IR-1038; IR-1074 will replace `text-body` in `Input`, `Select`, `fieldClasses` and `Button`.
