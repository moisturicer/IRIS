## IR-1046

**Requirement:** **An owner sends the revised manuscript from the Revision requested card, as they send a requested document from its row** — follows IR-273 (*Upload revised manuscript* was only in Files); no FR- id

**Design:** [ADR-032 §5](../../adr/032-adviser-first-review-and-office-reviewer-pools.md) with its IR-273 Amendment (an owner's upload is stored, not extracted, until its version is submitted) · Jira IR-1046

**Implementation:** `paper-view/RevisionManuscriptUpload.tsx`, rendered in the card for the `replace_manuscript` capability only, through the existing `PATCH /records/<id>/` manuscript upload (`recordsApi.uploadManuscript`), which the server already restricts to an owner while a revision is open. A compact Upload button, a progress bar while it goes, a success toast, and the page re-reads the record so `manuscript_unsubmitted` turns the button into **Replace revised manuscript** with "Revised manuscript ready, not yet submitted". A non-PDF or a file over 50 MB is refused before sending; a refusal or failure is a persisting error toast and the control goes back to a button; a second pick while one is running cannot send twice. The card's copy no longer sends the owner to Files. Reviewers keep reading the submitted manuscript until the new version is submitted (unchanged server behaviour).

**Test:** `paper-view/RevisionManuscriptUpload.test.tsx` (uploads and tells the page; Replace and the staged note; a server refusal is a toast and leaves the page alone; a non-PDF is refused before sending) · `paper-view/PaperViewPage.test.tsx` (the card shows the control and the staged note with `replace_manuscript`, shows none without it, and still opens Submit new version)

**Evidence:** 2026-11-12, worktree: same run as [IR-1044](IR-1044.md). **Not seen in a browser** (no Docker or PostgreSQL here), so the control's layout at 360 px is unchecked. Removing a staged upload is IR-1047, which needs a backend endpoint.

**Status:** **PARTIAL** — implemented and tested in jsdom; not yet seen in a browser, awaiting CI and review
