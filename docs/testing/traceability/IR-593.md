## IR-593 — the bounded conversational controller

**Requirement.** [ADR-042](../../adr/042-general-tools-conversation-contract.md) and the [general-tools spec](../../architecture-review/2026-10-15-askiris-general-tools-spec.md) §2, §7, §10: one controller where `PLAN` chooses tool calls, a clarification or ready-to-compose; only the application runs tools; `ANSWER` writes all public prose; answer capacity is reserved before research; rounds, tool calls, read concurrency and repair are bounded; duplicate no-progress loops stop without an LLM judge; versions are pinned per run.

**Built.** `apps/ai/controller/`: `loop.Controller` drives `general_tools()` through `ToolRegistry.invoke` with run-scoped handles, offers only the five general tools (no `plan_research`/`continue_plan`/`subtask_done`/`finish`), reads the original request, the resolved question as a hint, the committed conversation state and readable history, and re-gates every envelope each round (a revoked record or a changed metadata population drops the envelope and the last exchange). The finish signal is a JSON reply with no tool call (`prompts.decision_from`); planner text is never published. `compose.ReadyToCompose` → `AnswerComposer` is the ANSWER seam IR-594 replaces; it cites ledger passages through `generate_cited`, and an evidence request with nothing readable gets the existing `no_sources` wording, so empty, withheld and irrelevant read alike. `budget.ControllerBudget` reads six `AI_CONTROLLER_*` settings with no defaults (unset → unavailable, no model call); `FAKE_TEST_PROFILE` is spec §7's 4 rounds, 6 tool calls, 2 concurrent reads, 1 repair. Answer tokens and seconds for the answer plus its repair are reserved before every PLAN call and tool call. The run's wall clock is the shorter of `AI_RESEARCH_WALL_CLOCK_SECONDS` and the time left in the original deadline (a queued run's 30 s default is not extended). `ChatOrchestrator` takes the run's engine from `ChatQuestion.engine` or `CompositionRoot.engine` (`controller/versions.py`); durable submission pins it into `AskRun.request["pin"]`, a run without one is legacy, and an unknown engine ends `failed` with no Turn. The Turn's state commit names what was shown: papers cited in order, or a pending clarification.

**Recorded contradiction.** The IR-593 ticket asks for a "default-off controller" setting with legacy lanes as rollback. ADR-042 (Accepted) says there is no on/off switch and rollback is a code rollback; ADR-042 governs. No setting selects the engine: `NEW_RUN_ENGINE` in code stays `lanes-v1` until ADR-042's release gates pass (IR-594–IR-597), and tests select the controller through the composition root.

**Not built here.** Answer validation and the bounded repair (IR-594; the slot is only reserved); public activity events and serializers (IR-595 — the controller emits only `retrieval_started` and `done`, no tool names or routing); UI (IR-596). Reads run sequentially in waves no wider than the bound: a threaded executor needs `contextvars.copy_context` and per-thread database connections and belongs with IR-597's worker verification. The answer reserve is held in the controller's own token and time budget; it is not reserved in the admission ledger. The router's injection screening has no replacement yet. Record abstracts are context, not citable sources.

**Evidence (2026-10-16).** `apps/ai/tests/test_controller_http.py` (19 tests, `/ask/`, `/ask/stream/` and the queued worker, fakes only): no-tool direct answer composed by ANSWER with planner text discarded and only general tools offered (A08); discovery then rewording keeps the papers shown (A01/A08); ordinals resolved from the committed order, both papers read and cited (A01/A02); ceremony tool and malformed arguments rejected and stopping the run; duplicate and no-new-evidence loops stopped; round and tool-call limits; answer reserve preventing research; unset limits refusing; Paper Chat scope; a failed tool plus a PLAN outage keeping supported parts (A09); clarification composed and kept pending; revocation mid-run reaching neither planner nor answer; a stale metadata count dropped; engine pins surviving a rollback in both directions and an unknown pin ending without a Turn.
