# IR-574: Catalogue comparison picker and confirmed Conversation deletion

**Requirements:** FR-M4-01, NFR-A1, NFR-U3; ADR-026 explicit scope, ADR-046 declared origin; user-requested deletion confirmation (2026-11-02).

Ask IRIS selects 2 to the status endpoint's configured maximum catalogue Records, filtered by search and Area, with explicit origin labels. Removable selections stay with each Conversation and reach the existing comparison path as IDs. Scoped Conversations cannot select comparisons. No planner, answer engine or comparison output is added.

Deleting a Conversation now requires a named confirmation, with Cancel initially focused, pending/error/retry handling and one active phone focus trap. The existing immediate-delete regression was deliberately updated for this requested behavior.

Chromium verified desktop and 360 px layout, limits, request wiring, focus, keyboard handling and deletion confirmation; the answer SSE was deterministic. See [executed evidence and limitations](../evidence/IR-574/README.md). Automated test/build/lint evidence comes from GitHub CI. No requirement status or human sign-off is promoted here.
