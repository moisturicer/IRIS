# IR-1160: A reader renames a Conversation

**Requirements:** IR-1154 (reader controls in Ask IRIS), ADR-049 (AI-owned Conversations). The matrix has no `FR-` row for this.

## What changed

**Schema, `ai/runs/migrations/0020_conversation_title.sql`.** `iris_ai.conversation.title`, nullable, 1–200 characters with no surrounding whitespace. NULL shows the first question, as before. `_delete` clears it with the rest of a Conversation's content. Additive; existing rows read NULL.

**Runtime.** `RunStore.rename` sets the title under the reader's `reader_session` grant, with the same ownership and Paper Chat scope as reopen and delete; anything else is the same 404 as a missing Conversation. A blank or absent title stores NULL. `PATCH /api/v1/ai/conversations/<id>` takes `{title}` and answers the title now shown; over 200 characters is a 422 `title_too_long`. The list and reopen read `coalesce(title, first question)`.

**Page.** Each row of the history list has Rename. Enter saves, Escape cancels and returns focus to Rename, an over-long title is refused in place with "A title can be at most 200 characters.", and a server refusal is shown the same way. The toolbar heading and the tab title follow the new title. Paper Chat's Recent chats list reads the same list route, so it shows the new title too.
