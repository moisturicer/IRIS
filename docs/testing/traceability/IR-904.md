## IR-904

**Requirement:** **A small Playwright smoke tier gates every pull request that touches `frontend/`, against the built app with the network mocked** — no FR- id; subtask of the browser-test work around IR-631. The full-stack journeys stay off the PR path (IR-631 Q7)

**Design:** Jira IR-904 · [`../CORE_JOURNEYS.md`](../CORE_JOURNEYS.md) · [`../../../e2e/README.md`](../../../e2e/README.md)

**Implementation:** `.github/workflows/frontend-smoke.yml` (runs on every PR, decides in-job whether `frontend/` or the smoke tier changed, builds `frontend/dist`, runs `npm run test:smoke` in `e2e/`, records the job time, uploads the report, traces and videos); `e2e/playwright.smoke.config.ts` (serves the build with `vite preview`, parallel, no retries, trace and video kept on failure); `e2e/smoke/support/mock-api.ts` (every `/api` request answered by the test; an unclaimed request is answered 501 and fails the test); specs `e2e/smoke/auth.spec.ts` and `discover.spec.ts`

**Test:** The eight smoke specs: signed-out redirect, sign-in axe check, rejected credentials, valid sign-in to Discover, session restore from the stored refresh token, Discover listing and empty state, not-found inside the shell. The strict mock was seen to fail the run: the first run named `/dashboard/stats/` and ten other unmocked requests, then `/library/saves/`, until each was mocked

**Evidence:** 2026-11-06, local: `npm run build` in `frontend/`, then `npx playwright test -c playwright.smoke.config.ts`: 8 passed in 39 s (6 workers); `tsc --noEmit` in `e2e/` clean. Not yet seen on GitHub Actions: the artifact upload, the job-time summary and the non-frontend skip path are unrun

**Status:** **PARTIAL** until the workflow has run on a pull request and a repository admin has marked the "Frontend smoke" check required on `main`. A failing test fails the check; only the branch-protection rule makes that block the merge
