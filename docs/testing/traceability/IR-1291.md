## IR-1291

**Requirement:** Below 768 px the office console shows each review as a stacked card, not a row of a five-column table, so at 360 px and 375 px the paper title is not squeezed, nothing runs off the screen and the clearance lines are not shrunk. A card shows the same facts and acts as its table row. From 768 px the table is unchanged. No FR- id.

**Design:** Approved by the project lead in the colour proposal prototype, section "The office console on a phone". The card is, top to bottom: the title in EB Garamond; the authors and Version, then who holds it and the due date; the status chip; the clearances; one full-width action, where *Assign* is the primary button for an unassigned review and the existing row menu is an outlined *More actions* button otherwise. The overdue chip takes its outline from IR-1290's shared tones.

**Implementation (frontend only):**

- `features/review/OfficeConsolePage.tsx`: `useMediaQuery(PHONE_QUERY)` picks a card list or the table, so only one is in the accessible tree. `ConsoleCard` is new; `StatusChip` and `menuItems` are shared with `ConsoleRow`. The `max-sm:` classes that stacked table cells below 640 px are removed, since the table is no longer drawn there.
- `features/accounts/RowMenu.tsx`: a `wide` option draws the trigger as a full-width outlined *More actions* button; its accessible name is unchanged.
- `components/shared/ClearanceStrip.tsx`: a `stacked` option, one office per line. A card sets it only when an entry carries a note ("Kept from v1").
- `lib/layout.ts`: `PHONE_QUERY` is exported (it already defined the 768 px breakpoint the sidebar uses).

**Test:**

- `features/review/OfficeConsolePage.test.tsx`, "on a phone": cards and no table; the table from 768 px; each card carries its row's facts in the server's words; one primary *Assign* on an unassigned card; only *More actions* on a held card; no action area when the server offers nothing; stacked clearances only where a note is present; axe-clean.
- `features/accounts/RowMenu.test.tsx`: the wide trigger opens the same menu.
