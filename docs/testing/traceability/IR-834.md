# IR-834 — authenticated PDF preview beside Publish Details

[Back to the matrix](../TRACEABILITY.md)

**Requirements / authority:** IR-834 acceptance criteria; ADR-053 threat model for authenticated
file/object access; existing Publish journey and shared `PaperPdfReader` contracts.

## Implementation

- `frontend/src/features/publish/PublishDetailsPreview.tsx` composes the existing metadata form with
  the shared authenticated PDF reader.
- Wide layouts show the accepted Manuscript beside Details; narrow layouts expose labelled
  Details/Preview controls and preserve keyboard focus.
- `PublishDialog.tsx` widens only the Details step and keys the reader to the accepted-source
  generation, so a successful replacement remounts the reader.
- `ManuscriptStep.tsx` distinguishes the accepted Manuscript from a failed replacement attempt.
  A rejected replacement therefore keeps the preceding accepted source and Continue path.
- No dropped local file, raw storage iframe, office-selection change, Published label, scanner
  state or malware verdict was added.
