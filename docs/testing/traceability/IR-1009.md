# IR-1009: a thread says why it isn't followed into a later Version

**Requirements:** no FR- id. A follow-up to IR-876's *Outdated threads* ([ADR-032](../../adr/032-adviser-first-review-and-office-reviewer-pools.md) §7).

## What was wrong

To follow a thread's passage into a later Version, both Versions need review text (IR-871, IR-876). When one had none (a scan, or a file the reader couldn't read, as with IR-1005), the thread was never placed and its card said nothing, so it looked the same as a passage that hadn't moved. In the IR-876 Docker test this looked like a bug, until the Changes tab showed *no text for v1*.

## What changed

- `comments.comment_payload` adds `not_followed` to each top-level thread: `{version, message}` or null.
  - It is given only for an open, anchored thread with a later Version it hasn't been placed in. It follows from the anchor Version, or from the newest Version the passage was found or changed in.
  - It names the first missing text: *Can't follow this passage into v2: no text for v1.* or *…: v2's text was not kept.*
  - Otherwise, while the text is still being read or placing hasn't run yet: *Looking for this passage in v2.*
  - It is null for a draft, a resolved thread, a thread already placed in the newest Version, or a removed passage (followed no further).
- The Versions and their texts are read once per listing (`_Viewer.versions`), not once per thread. Nothing is queued or read: this reports state only.
- The thread card shows the message under the quote. A value of the wrong shape is ignored.

## Evidence

- `apps/reviews/test_not_followed.py`: six tests at the REST seam. All failed before the change (`KeyError: 'not_followed'`) and pass after:
  - a Version with no text is named;
  - a text not kept is named;
  - pending, then read but not yet placed: *Looking for…*;
  - it follows on from the newest Version the passage was found in;
  - nothing with a single Version;
  - nothing once placed in the newest Version, removed, or resolved.
- `ThreadPlaces.test.tsx`: the card shows the reason, and ignores a reason of the wrong shape.
- Run 2026-11-10 on Windows:
  - `test_not_followed`, `test_suggested_wording`, `test_review_comments` and `test_review_threads`, against a throwaway pgvector container: 98 passed;
  - flake8 is clean;
  - `tsc` and `eslint` are clean;
  - `vitest` on `paper-view/threads`: 79 passed.
