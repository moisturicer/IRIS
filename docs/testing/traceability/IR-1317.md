## IR-1317

**Requirement:** An owner who uploads the wrong supporting document can delete it, its first upload included, from the paper's Documents tab and from Publish's Documents step. ADR-058 §2: *"A draft's files are free to delete until it is first submitted."* What the review relied on stays, for everyone. The manuscript is unchanged. No FR- id.

**Basis.** `delete_upload` refused version 1 unless an office overrode it. The rule came from the May MVP (`6195132e`) with no ADR, and contradicted ADR-058 §2. The Documents tab still offered Remove on version 1, so the click failed.

**Implementation:**

- `backend/apps/documents/services.py`: `delete_upload` no longer refuses version 1 and loses its `force` argument. `deletion_refused_reason` still refuses a file a Version names, one that answered a document request, and one a review thread is about.
- `backend/apps/documents/views.py`: `RecordUploadDeleteView` no longer computes an office override. Who may delete is unchanged (`owns_or_staffs_record`).
- `frontend/src/features/publish/DocumentsStep.tsx`: each slot's latest upload has Remove, behind a confirmation; a kept file shows "Kept" with the server's reason.
- `frontend/src/features/records/paper-view/DocumentsTab.tsx`: `RemoveButton` exported for that.
- Manuscript upload, replace and discard: untouched. The manuscript has no `UploadSlot`, so it never reaches `delete_upload`.

**Tests:**

- `backend/apps/documents/tests/test_upload_deletion.py`: the owner deletes version 1 (row and stored file gone); version 1 lists `delete_refused: null`; deleting it leaves version 2.
- `test_rejection_history.py` (unchanged): a rejected upload is still kept.
- `frontend/src/features/publish/PublishDialog.test.tsx`, "documents": Remove asks, deletes version 1 and empties the row; a kept file has no Remove and states the reason.

**Runs** (2026-11-24, Windows 11, local Postgres):

- `test_upload_deletion.py`, `test_document_access_control.py`, `test_rejection_history.py`, `test_record_document_authorization.py`: 58 passed, 1 skipped, 6 failed. The 6 upload through `documents/submit/`, whose PDF check needs Linux; they fail the same way without this change. Left to CI.
- `PublishDialog.test.tsx` and `DocumentsTab.test.tsx`: 160 passed. `tsc --noEmit` and eslint on the changed files: clean.
