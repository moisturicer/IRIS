## IR-1210

**Requirement:** My Reviews' "Overdue only" filter clears when the tab changes, as Done's outcome filter already does, so a highlighted filter always matches the list shown

**Design:** Jira IR-1210 (team testing, 2026-11-17). The ticket left open whether filters should all reset or all persist across tabs; they reset, because Done's outcome filter already did and the report asked Overdue only to match the others

**Implementation:** `frontend/src/features/review/MyReviewsPage.tsx`, `go()`: when the tab changes, `overdue` is set to false before the URL is written. Sort is unchanged (one sort is always selected), and a URL that carries `overdue=1` still opens with it on

"comes back to the sort and filter it left, from the URL" still passes
