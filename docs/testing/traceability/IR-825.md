# IR-825: production containers reach the internet only if they need to

**Requirements:** NFR-S3

`docker-compose.prod.yml` puts every service on an internal `private` network, and only those that call a vendor, send mail or get certificates also join `egress`. `apps/tests/test_container_egress.py` pins each service's networks, and CI's Docker Compose job shows `private` and `redis` can't reach the internet while `egress` can.

**Not proven:** the full stack on these networks, which needs the manually started core journeys. That includes Docling converting a PDF with no internet. Services on `egress` aren't limited to named hosts; `SECURITY.md` §7 records why.
