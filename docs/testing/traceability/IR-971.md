# IR-971: Setup, RDCO manages each record type's requirements, Templates and description

[Back to the matrix](../TRACEABILITY.md)

**Requirements:** FR-M2-01 (stable label only). Story IR-969, epic IR-671 (S2 Epic: Backend). [ADR-063](../../adr/063-rdco-sets-requirements-and-templates.md) decisions 1-5 and 8-12, as amended by [ADR-066](../../adr/066-ip-applications-beside-publishing.md) decisions 20-23.

## What changed

- **A Requirement is the existing `UploadSlot`** (decision 1). It gains `description`, `position` and one current Template (`template`, `template_name`), plus `hidden_at` for a removed requirement that a paper used. `RecordType` gains `description`, `manuscript_description` and the Manuscript's Template (decision 4: the Manuscript is the paper itself, not a slot). Migrations `documents/0024`, `records/0041`, `audit/0028` (event choices).
- **Starting labels** (`documents/0025`, decision 12 as ADR-066 amends it). Required: Thesis Revision Form and Patent Search Report on a Proposal; Community Extension, Publication / Conference Presentation / Both and Release Form on Thesis / Research and Project. Everything else is Optional. ADR-063 decision 12 also named Intellectual Property Application Status, the Commercialization Assessment and Project's Patent Search Report Required. **ADR-066 decisions 21-22 take those off the submission**, so they stay Optional here and **IR-1062 removes them**, with the slots for an IP application kind or a commercialization application. Each type's slots keep the order they always showed in, numbered from 1. **Descriptions start empty**: RDCO's sheet isn't in the repository, and the owner chose on 2026-11-14 to let RDCO write them on Setup.
- **Setup API**, RDCO-only (`IsRDCO`, a role gate before any lookup), in `apps/documents/setup.py` and `setup_views.py`:

  | Route | Does |
  |---|---|
  | `GET setup/record-types/` | every record type, its descriptions, the Manuscript row and its listed requirements, each with `in_use` |
  | `PATCH setup/record-types/<id>/` | `description`, `manuscript_description` |
  | `PUT`/`DELETE setup/record-types/<id>/manuscript-template/` | the Manuscript's Template |
  | `POST setup/record-types/<id>/requirements/` | add, at the end |
  | `PUT setup/record-types/<id>/requirements/order/` | reorder; must name every listed requirement once |
  | `PATCH`/`DELETE setup/requirements/<id>/` | edit name, label, description; remove |
  | `PUT`/`DELETE setup/requirements/<id>/template/` | a requirement's Template |

- **Template downloads**, for anyone signed in: `GET slots/<id>/template/` and `GET record-types/<id>/manuscript-template/`. Always `Content-Disposition: attachment` with `nosniff`, only for a listed requirement, not audited (decision 11).
- **Template files** (decision 8, `template_files.py`): PDF, `.doc`, `.docx`, `.odt`, `.xls`, `.xlsx`, `.ods`, `.png`, `.jpg`, `.jpeg`, up to 50 MB. The extension **and** the file's first bytes must agree, so a program renamed `form.pdf` is refused. No parser runs on a Template, since it is never opened in IRIS. A replaced or removed file is deleted from storage after the change commits.
- **Removing** (decision 5): a requirement that a paper has uploaded to, or that a document request asked for, is hidden. It leaves Setup, `slots/`, the request picklist and new uploads, and stays on that paper's `records/<id>/slots/` with `hidden: true`. An unused one is deleted.
- **Names**: required, at most 200 characters, never "Manuscript", unique among a type's listed requirements (case-insensitive). Descriptions are plain text up to 2,000 characters.
- **Audit** (decision 11): `REQUIREMENT_ADDED`, `REQUIREMENT_CHANGED`, `REQUIREMENTS_REORDERED`, `REQUIREMENT_REMOVED` (`outcome` hidden or deleted), `TEMPLATE_REPLACED`, `TEMPLATE_REMOVED`, `RECORD_TYPE_DESCRIBED`. Descriptions are recorded as character counts, never their text.
- **Where slots show**: `slots/`, the request picklist and `records/<id>/slots/` now read the shared `listed_slots`/`slots_for_record`, in RDCO's order, and return `description`, `position` and `template_name`. Showing them as compact rows in Publish and Paper View is IR-973.
- **Client**: `/rdco/setup` (`features/setup/SetupPage.tsx`), an RDCO sidebar entry "Setup". One tab per record type: its description, then the Manuscript row and each requirement, with Required/Optional, description (links clickable, `PlainTextWithLinks`), Move up/down, Edit, Remove (the dialog says whether it will be hidden or deleted), and Template upload, replace, download and remove. The Notice section is IR-972.
- **`seed_demo`** adds its demo "Revised ethics consent form" slot as Optional and last, instead of the model's default (Required, position 0).

## A test changed on purpose

`backend/apps/documents/test_upload_slot_requirements.py` asserted that **no slot may be Required** (IR-118). ADR-063 decision 3 reverses that under a rule that keeps IR-118's point: a label never blocks submitting. The file now asserts the exact starting labels, that a submission with every Required slot empty is accepted, and IR-118's two remaining tells (no type requires two alternative IP protections; the Patent Draft is never required). Its "no office output is demanded" check no longer counts the Proposal's Patent Search Report, which ADR-066 decision 22 keeps as the Proposal's own early check.
