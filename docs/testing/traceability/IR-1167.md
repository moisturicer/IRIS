# IR-1167: A reader downloads a Conversation as Markdown

**Requirements:** IR-1154 (reader controls in Ask IRIS), ADR-049. This is the reader's own download; the evaluation export stays with IR-740, as ADR-049's 2026-11-04 amendment assigns it.

## What changed

**Runtime.** `GET /api/v1/ai/conversations/<id>/export` reopens the Conversation under the reader's grant and renders `public.conversation(...)`, the same reader view reopening uses, through `public.markdown`: the title, then each Turn's question and answer in order, then its numbered sources with paper title, page and quote. An answer whose sources are no longer readable is the page's unavailable notice with no sources. Nothing else from the view is written: no plan, reasoning, usage, run state or codes. Reopen now names each cited paper, read under the grant, so an unreadable paper has no title. The file is `text/markdown`, named after the title.

**Edge.** `frontend/runtime-edge.conf` admits `/conversations/<uuid>/export` beside `/compact`, through the same edge grant; there is no other path to it.

**Page.** A download icon ("Download conversation as Markdown") sits in the Ask IRIS toolbar once a Conversation exists, and in Paper Chat's header beside New chat.

## Acceptance criteria

| Criterion | Evidence |
|---|---|
| Every Turn in order, citation numbers matching the answer | `test_the_download_holds_every_turn_in_order_with_numbered_sources` (exact file) |
| The file's title is the Conversation's title, renamed or first question | same test (renamed), `test_the_download_carries_no_internal_state` (first question) |
| An unreadable answer is the page's notice, with no citations | `test_an_unreadable_answer_downloads_as_the_notice_without_sources` |
| No reasoning, plan, usage or internal codes | `test_the_download_carries_no_internal_state` |
| Another reader's Conversation is "not found" | `test_another_readers_conversation_is_not_found` |
| Keyboard, accessible name, present in Paper Chat | `RAGChatPage.runtime.test.tsx` "downloads the conversation as Markdown through the runtime, by keyboard"; `PaperChatDock.test.tsx` "downloads its conversation as Markdown, scoped to the paper" |
| Served through the runtime under the reader's grant | the route sits behind `_call` and `RunStore.reopen`; `test_rename_and_export_need_a_valid_reader_session`; the page test asserts the request carries no grant of the browser's own |
