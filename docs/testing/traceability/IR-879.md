# IR-879: participants see Overview · Review, and Files move into Review

**Requirements:** none by `FR-` label. The rule is [ADR-032](../../adr/032-adviser-first-review-and-office-reviewer-pools.md) §10's 2026-11-04 amendment, corrected the same day: no Ask IRIS in Review.

What changed (frontend only):

- **Sections** (`features/records/capabilities.ts`). A participant's tabs are **Overview · Review**, and everyone else's **Overview · Paper**. Files is no longer a section. `landingSection` sends a participant's old `?section=paper` to Review, and `?section=files` to Review with the Documents drawer open. A cited page (`?page=N`) opens in Paper for a reader and in Review for a participant.
- **No Ask IRIS in Review.** "Ask about this paper" is gone from both review layouts. A participant opens Ask IRIS on Overview or at `/ai`.
- **Documents drawer** (`ReviewWorkspace.tsx`). An "All documents" dialog, full screen on a phone, holds the old Files section unchanged (`FilesSection`), with the same endpoints and checks. It's kept in the URL as `?documents=open`, and opened by:
  - the sidebar's new **All documents** button
  - a Readiness document-request link
  - the author's new **Documents** button
- **The sidebar's Documents** also lists the latest version's slot documents and anything added since (IR-872's `documents` and `documents_added`), and says when that list is reconstructed.
- **Links.** The Overview's *View* and *Manage files* go to Review for a participant, and FilesSection's manuscript link reads "Read it beside the review".
- **ADRs.** ADR-032 §10 is corrected (no Ask IRIS in Review). ADR-052 gains *embargoed by default* (built by IR-882), and ADR-056 gains *no AI auto-fill, Docling kept* (IR-883).

**Evidence:** run 2026-11-04 on Windows.

- `npx vitest run --maxWorkers=2`: **136 files, 1837 tests passed**.
- `tsc --noEmit` is clean. `npm run lint` gives 0 errors, and 3 warnings that were already present (none in changed lines).
- New and changed tests:
  - `capabilities.test.ts`:
    - 18 participant rows changed on purpose to Overview · Review
    - 8 new `landingSection` cases
  - `PaperViewPage.test.tsx`, changed on purpose:
    - owner and reviewer tab sets
    - arrow-key order
    - Open Documents opens the drawer
    - no Ask about this paper
  - `PaperViewPage.test.tsx`, new:
    - a participant's `?section=paper` lands in Review
    - a cited page opens in Review
    - `?section=files` opens the drawer, and closing it closes it
    - the author's Documents button opens the drawer
  - `ReviewWorkspace.test.tsx`: the new props.
