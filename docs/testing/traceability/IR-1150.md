# IR-1150 — The per-paper share is measured and off by default

**Affected requirement labels:** none change status. Part of IR-980; ADR-033, amended 2026-11-16.

[Back to the matrix](../TRACEABILITY.md)

**Implementation:**

- **Measurement.** `scripts/eval_paper_share.py` replays the runtime's passage selection (`ai/research/selection.py`) on candidates that are ranked once and then held fixed, under `paper_share` 0, 25, 33, 50, 75 and 100. Keyword mode is free. Hybrid mode embeds each query once with Voyage and caches the vectors.
- **Default.** `Policy.paper_share` is 0 (off). `RUNS_PAPER_SHARE` still turns the share on, from 1 to 100.

**Tests:** `ai/tests/test_passage_selection.py`. `test_selection_is_on_by_default_without_a_paper_share` now expects 0. This is a deliberate change to follow the new default, not a fix to make a test pass.

**Evidence:** the run files and the report in `docs/evaluation/runs/2026-11-16-ir1150-paper-share/` (proxy tier, ADR-023). The hybrid run billed 1,754 Voyage tokens.

**Not done:** the multi-paper case is unmeasured; the question set has five two-paper questions and no labelled "what do studies say" question.

**Status:** Partial; CI and human review pending.
