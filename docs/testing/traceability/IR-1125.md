# IR-1125 — Measure what the reranker should read for figures with no caption

**Affected requirement labels:** none change status. Part of IR-980; a technique switch under ADR-033 §5.

[Back to the matrix](../TRACEABILITY.md)

**Implementation:**

- **Switch.** `AI_RERANKER_READS` (`today`, `embedded`, `described`, `fallback`; default `today`) chooses the text `RerankingRetriever` sends for each passage (`apps/ai/retrieval/reranker_input.py`). Readers always see the shown text. Registered as `reranker_reads`, so `--list-techniques` lists it and every `eval_retrieval` run file records it. Retrieved chunks now carry their embedded text and element kinds.
- **Figure labels.** A label may name a page and a box instead of a quote; it hits a passage box on that page at IoU 0.5 or more. `--dry-run` checks it against the active or a trial chunk set.
- **Comparison.** `eval_reranker_input` recalls once per question and reranks those candidates under every arm. An input list already reranked for that question is served from memory, so an arm identical to today costs nothing. It reports per-arm, per-set recall@10 and final-set recall, per-question results, paired sign tests on "found in the top 10", rule 4 checked on the inputs actually sent, and the decision rule verbatim. A paid run reuses the dry pass's recall, needs `--labels-reviewed-by`, refuses an estimate past `--max-cost-usd` (2) and records Voyage's billed tokens.

**Tests:** `apps/ai/retrieval/tests/test_reranker_input.py`, `apps/ai/evaluation/tests/test_reranker_arms.py`, `apps/ai/evaluation/tests/test_figure_labels.py`, `apps/ai/evaluation/tests/test_techniques.py` (registry changed deliberately to add the switch).

**Evidence:** 2026-11-15, Windows 11 host: the four test files above pass (no database needed). The full suite is left to CI on the PR.
