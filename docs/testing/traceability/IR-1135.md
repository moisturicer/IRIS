## IR-1135 · My Reviews looks like the prototype: counted tabs, sort and outcome chips, Mine / All of office

My Reviews is where routing is read, so what each tab counts must equal the rows it
shows. The queue endpoint (`GET /api/v1/reviews/mine/`, `apps/reviews/my_reviews.py`)
already counted the three tabs and took `sort`, `overdue` and a coordinator-only
`office`. This change adds what the page still lacked and restyles it to the
redesign prototype (`#/reviews`, `viewReviews`).

**Backend.** The one response now also carries:

- `outcome_counts`: `all` plus one count per Done chip (Cleared, Finding recorded,
  Accepted, Rejected, Published), over both Done sources, for the viewer's scope
  (mine, or all of the coordinator's office). An outcome filter never narrows them.
  `revision_requested` is not a chip, so it appears only inside `all`.
- Per row: `authors`, `unit` (the primary owner's college), `version` (the latest
  Version) and `opens` (`review`, or `overview` once the paper is published). The
  browser maps no pipeline state to a place or a word. All four are read once for
  the page, so the query count stays flat in the number of rows.

**Frontend.** `MyReviewsPage.tsx`: a line under the title from the viewer's seat,
*Office console* and *Workflow analytics* as secondary buttons, underlined tabs with a
count each, outcome chips with a count each, *Mine / All of <office>* on the right of
the toolbar, rows as the prototype's kicker (authors · unit · vN · due) then title, and
the prototype's empty-state wording.

**Decisions to confirm.**

1. The ticket names `scope=mine|office` and "office staff". The endpoint keeps its
   tested `office=` parameter, and it stays coordinator-only (ADR-032 §9): a member
   naming an office, or a coordinator naming another one, is a 403. A member therefore
   sees no *Mine / All of* control. Widening the office view to members is a change to
   that ADR, not a styling change.
2. "Attention when due within the window": the server sends no window, and the browser
   invents none. A row is emphasised only when the server says `is_overdue`.
