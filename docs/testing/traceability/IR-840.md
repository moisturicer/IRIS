# IR-840 — Shape LlamaParse results and build chunks from their labels

**Affected requirement labels:** FR-M3-01, FR-M4. Matrix status is unchanged.

[Back to the matrix](../TRACEABILITY.md)

**Authority:** ADR-056 decisions 4, 8, 11–13. Docling remains selected until IR-842; its mapping, heading inference, furniture repairs and chunker remain available unchanged for legacy documents.

**Implementation:** `apps/ai/extraction/shaping.py::shape_llamaparse` is the pure read boundary for raw items, downloaded grounding, page metadata and document confidence. It preserves LlamaParse's kinds and heading levels, nested ordered lists, table grids and HTML, printed page numbers and line boxes. Unknown kinds become paragraphs with `source_label`. Display math becomes `formula`; the title is the first level-1 heading on pages 1–2, otherwise empty. No filename, numbering, repetition, folio or hyphenation inference is applied.

`PdfExtraction.as_normalized_document()` delegates to `read_document`; LlamaParse reads require `raw_result` and reshape it each time. `as_search_text()` flattens that same current document. IR-841 owns raw-result persistence and its migration, and already resolves `shaping.shape_llamaparse` when constructing its adapter. No adapter, backend switch, migration or provider call is added here.

Authoritative documents use `labeled-structure-v1` in `build_chunk_set` and in the ingestion key. Excluding sections remains a chunking choice. Heading paths use declared levels. Lists and Figures stay whole; oversized tables split between rows and repeat the first/header row. Tables embed row text and display the supplied HTML cells, preserving column spans and clipping/continuing row spans across fragments. Figure captions display and embed, with a separate retrieval-only description slot for IR-852. Formulas never enter embedded text. Prose budgets count the final context prefix using the vendored Voyage tokenizer, and bound the prefix before splitting. An indivisible list, Figure, table row plus header, or grapheme can exceed the target rather than lose content. Containers retain their children's available line evidence; row coordinates are not invented when the recording has no cell grounding. The labeled strategy's set hash includes display content, regions and page sizes, so a formula/HTML/evidence-only edit refreshes stored chunks while the unchanged per-chunk text hash reuses vectors. Legacy hashes and Voyage's paper grouping/provider code are unchanged.

**Approved test boundaries:** shaping; chunk generation through `build_chunk_set`; stored Extraction document/search reads. `test_shaping.py`, `test_labeled_structure.py` and `test_shaped_extraction.py` cover these. New behavior was exercised as failing tests before implementation; an initial link test used `value`, and was deliberately corrected to the vendor's documented `text` field, then failed before the fix.

**Recordings:** the four synthetic PDF results and grounding files are copied byte-for-byte from IR-841's completed development recording of IR-849's fixtures. They replace no real Manuscript and CI calls no vendor. The recording shows no image items or list items, so those cases use authored payloads matching the [official response-format contract](https://developers.llamaindex.ai/llamaparse/parse/guides/response-format/#item-types), checked 2026-11-03. `OPEN_CONDITIONS.md` records the observed formula, confidence, cost and Figure limitations. IR-851 still owns acceptance on the 40-paper proxy corpus; IR-845/852 own Figure storage, display and description generation.

**Review:** parallel Standards and Spec reviews found four material issues: display-only edits could be treated as unchanged, prefix pressure could split ordinary words unnecessarily, list containers lost child line boxes, and split tables lost merged cells. Each was reproduced through `build_chunk_set` before its fix. Shared recording builders were also moved out of a test collection module. The two review axes are being rechecked after these fixes.

**Evidence (2026-11-03):** initial extraction, chunking and stored-read regression suite: **392 passed**; four review regressions bring the final boundary count to **23 tests**. Python typechecking uses a temporary mypy installation, with `--follow-imports=silent --ignore-missing-imports --check-untyped-defs`, on the eight changed domain modules; lint uses the repository's flake8 configuration. The first full-suite attempt ran 5,448 tests successfully but its read-only source mount prevented upload fixtures from writing `media`, causing 157 failures and 129 setup errors; there was also a contended-machine Hypothesis health check and a CRLF-sensitive proxy fixture digest failure. That environment is not acceptance evidence. A corrected full run uses a writable Linux snapshot of the committed tree, the documented CI Hypothesis profile, `ai/requirements.txt`, no development `.env`, `IRIS_REQUIRE_DB=1` and a disposable pgvector database. Results will be recorded before review handoff.

**Status:** Implemented; full-suite evidence, independent review, CI and human approval pending.
