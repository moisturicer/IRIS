# IR-1276: The sidebar is 256 px, so no item wraps

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** no sidebar item takes two lines. Reported by Hermoine Zozobrado on 2026-11-23. No FR- id.

**Design:** no ADR change. This changes the width set by [IR-413](IR-413.md) and kept by [IR-1086](IR-1086.md). The 76 px icon rail and the breakpoints are unchanged.

## Why 256 px

The 240 px sidebar leaves a label about 159 px. A count badge and its gap take about 32 px of that, which leaves about 127 px. Measured in Inter at 14 px, from the font file this app loads, **Download requests** needs 130 px and **Reported comments** 137 px when bold (the current page's weight). So both wrapped whenever their queue had a count. Every other label fits. The longest without a badge is *Calls & Conferences*, at 137 of 159 px.

At 256 px a label beside a badge has about 143 px, so both fit with about 6 px to spare.

## What changed

- `Sidebar.tsx`: `w-60` → `w-64` (the phone drawer, the tablet's opened sidebar) and `md:w-60` → `md:w-64` (the desktop sidebar).
- `AppShell.tsx`: the desktop page margin `lg:ml-60` → `lg:ml-64`, so the page still starts where the sidebar ends.
- Docs that state the width: `lib/layout.ts`, `docs/ui-ux/01-design-system.md`, `03-navigation.md`, `13-responsive.md`.
