## IR-477

**Requirement:** **A cited passage lands clear of the Review tab's sticky action bar** — follow-up to IR-412, IR-374 redesign; no FR- id

**Design:** [frontend_redesign_spec](../../frontend_redesign_spec.md) Appendix K (amended 2026-11-01) · Jira IR-477

**Implementation:** `PaperPdfReader` takes `bottomInset` (px, default 0). Below `reading-wide` its window reading band is `windowReadingBand(toolbar, innerHeight, bottomInset)`, so a citation lands, and find counts a match in view, only above the inset; `contained` ignores it. The author's Review tab (`AuthorReviewWorkspace`, formerly `ReviewSection`) measures its action bar's border box with a `ResizeObserver` (`useElementHeight`) and reports it through `onBarInset`, 0 once the tab closes; `PaperViewPage` passes it only on the Review tab. The reviewer workspace is unchanged: its reader is contained.

**Test:** `paper-view/reviewLanding.test.ts` (the bar-aware band replaces the ~350px limit) · `paper-view/readerGeometry.test.ts` (`windowReadingBand`) · `paper-view/PaperPdfReader.test.tsx` (landing and find with an inset; IR-354 cases unchanged) · `paper-view/ReviewWorkspace.test.tsx`

**Evidence:** Single test files run locally while building; CI on the IR-477 PR. [Browser evidence](../evidence/IR-477/README.md): 360×740, real pdf.js rendering with browser-only fixtures; 400px/480px passages clear the measured 112px bar, 600px starts below the toolbar, Find scrolls a hidden match above the bar
