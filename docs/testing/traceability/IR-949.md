## IR-949 — Your own Profile shows Research, Advised and Collaborators

**Basis and scope.** Continues IR-948 under IR-694. `/profile` now reads the three paged lists from the IR-696 endpoints using the signed-in user's id. The profile header continues to come from the authenticated account, so it does not make a duplicate public-profile request. It mounts the same `PersonProfileView` used by `/people/:id`, which supplies independent pagination, retry, Show more focus, empty paper state and collaborator links.

The empty-paper message waits until both paper lists have completed successfully. Initial loading and loading another page have separate state, so an in-flight request is not presented as an empty profile. A failed request stays visible as a list-level error with its own retry. `/people/<own id>` continues to redirect to `/profile`.
