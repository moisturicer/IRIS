# IR-737 — Recoverable committed Manuscript work

[Back to the matrix](../TRACEABILITY.md)

**Basis and scope:** ADR-049 §22, IR-716 and the approved IR-737 design. Django
commits source changes and canonical work atomically. Exact-work/revision/purpose
grants bind a monotonic authority generation. Access and canonical embargo stamps
invalidate old authority while keeping current work recoverable. The separate
AI ingestion process owns acknowledgements and generation-bound cleanup receipts.
Deletion facts survive hard deletion. Existing extraction remains in place;
extraction is IR-738 and indexing/publication is IR-751.

11 IR-737 tests plus vocabulary and traceability checks. Linux/PostgreSQL tests
exercise authenticated PDF upload/submission, rollback, exact source authority,
restricted-role refusal, lost publication, independent worker races, historical
identity, access/embargo generations, durable deletion and delayed cleanup.

switch or provider call occurred. Python lint/compilation and diff checks pass.
