# IR-751 — Current indexed Manuscript publication

Authority: ADR-049 and the accepted IR-716 publication specification.

AI-owned indexing consumes IR-738 immutable extraction output. Record summaries
and consecutive contextual Passage windows use the existing tokenizer/window
semantics, explicit current Embedding Space identity, and the shared provider
campaign ledger. Each immutable completed batch retains its reservation identity.
Lease recovery reuses completed output; unknown sends stay conservatively charged
and any repeat requires another admission under the original persisted job caps.
The ingestion lane and process are separate from reader execution.

Canonical source, generation and disclosure checks fence sends and publication.
The active pointer changes atomically only after complete vector coverage checks.
Local keyword and optionally configured semantic research read the new current
revision; saved citations preserve the revision and are withheld after its
permission/source changes. Existing Django writers remain untouched.

Behavioral coverage: `backend/apps/ai/tests/test_runtime_indexing.py`, through
restricted PostgreSQL workers, independent processes and authenticated run routes.
See [verification evidence](../evidence/IR-751/README.md) for executed results and
limitations. This document does not grant deployment or paid-campaign approval.
