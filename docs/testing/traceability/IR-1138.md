# IR-1138: RDCO tools follow the prototype, with queue counts in the sidebar

[Back to the matrix](../TRACEABILITY.md)

**Requirements:** no FR- id. Part of epic IR-920 (S2 Frontend UI/UX Redesign).

## What changed

- `GET /dashboard/queue-counts/` (`QueueCountsView`, RDCO only) returns the pending download, delete and role request counts. Role requests count verified accounts only, as the Role Requests queue lists them.
- The sidebar reads it once for RDCO, again when the address changes and when a queue page calls `queueCountsChanged()` after a decision (`lib/queueCounts.ts`). Role, Download and Delete requests each show a count with the accessible name "N pending"; nothing at zero or when the read fails. Any other role never asks. The older role-requests read and its "waiting" wording are gone.
- Pages follow the prototype: Import records (three step cards over one upload area), Users (description, search placeholder), Role requests (description, "No role requests" empty state), Download requests (description, Approve primary, Decline quiet), Delete requests (description, Decline quiet; Approve deletion stays the danger button), Notices (publish form beside a "Live now" panel).

## Tests

- `backend/apps/records/test_queue_counts.py`: empty queue, RDCO sees only pending, student and ITSO refused, anonymous refused.
- `Sidebar.test.tsx`: three counts, none at zero, none on a failed read, falls after a decision without a reload, Student, ITSO and System Admin never ask.
- `RoleRequestsPage.test.tsx` changed deliberately: "All caught up!" became the "No role requests" heading.

## Evidence and limits

- Ran locally 2026-11-15: Sidebar, admin, accounts and Import page tests (131) pass; `tsc --noEmit` clean.
- **The backend test was not run locally** (no database or `.env` in this worktree); CI is its first run.
- **Not checked in a browser.**
- Not built, needing API fields or endpoints that do not exist: status counts on the Delete requests filter, Users Unit and Last active columns, role filter, CSV-plus-PDF import with a row check, Save draft on Notices.
