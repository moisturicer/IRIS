## IR-1047

**Requirement:** **An owner can discard a revised manuscript they uploaded and have not yet submitted, putting the submitted manuscript back** — follows IR-273 (the only ways back were to upload another or for the last request to be withdrawn); no FR- id

**Design:** [ADR-032 §5](../../adr/032-adviser-first-review-and-office-reviewer-pools.md), Amendment 2026-11-12 (**proposed**, awaiting the project lead's review) · Jira IR-1047

**Implementation:** `POST /records/<id>/discard-revised-manuscript/` (`RecordViewSet.discard_revised_manuscript`), answering with the record detail. `reviews/new_version.discard_revised_manuscript` locks the record, refuses a non-owner (403) and, with 400s that say which, a record with no open revision request or no unsent upload, then calls `versions.restore_submitted_manuscript` (the restore a withdrawn last request already runs) and writes one `REVISION_DRAFT_DISCARDED` audit event (`version`, `discarded_revision`; migration `audit/0027`). Nobody is notified. `core.permissions` offers `discard_revised_manuscript` to an owner while a revision is asked for and `manuscript_unsubmitted` is true. Edited details and uploaded documents are untouched. The Paper View button is a separate change.

**Test:** `apps/reviews/test_discard_revised_manuscript.py` (the record reads the submitted version again; answers with the detail; the request stays open and submitting is refused as unchanged; the owner may upload again and submit; reviewers read the submitted version throughout and nobody is notified; offered to the owner only while an upload waits and never to a reviewer; a reviewer is refused and the upload stays; nothing unsent, a second discard, no revision asked, a draft and a withdrawn last request are 400s; one audit event naming who and which version) · `apps/records/test_capabilities.py` (new state `revision_asked_and_revised` and a probe for the key) · `apps/tests/access/table.py` (`record-discard-revised-manuscript`)

**Evidence:** 2026-11-12, worktree: `python -m py_compile` on every changed backend file. **Backend tests were NOT run locally**: this machine has no PostgreSQL, Docker or backend dependencies installed, so none of the tests above have executed and the audit migration has not been checked with `makemigrations --check`; CI runs them. The migration copies `audit/0026`'s choices with one entry added after `REVISION_REQUEST_WITHDRAWN`, in the model's order.

**Status:** **PARTIAL** — implemented, not yet executed; awaiting CI, review and acceptance of the ADR-032 amendment
