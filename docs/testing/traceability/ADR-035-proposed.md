## ADR-035 (proposed)

**Requirement:** **Ask IRIS decides whether it needs evidence** — no FR- id; [ADR-035](../../adr/035-ask-iris-decides-whether-it-needs-evidence.md) is the requirement **once accepted**, and it is `Proposed`, not accepted. IR-461 under [IR-456](https://citiris.atlassian.net/browse/IR-456) — the evidence decision, Phase 0 and a reader-invisible shadow pilot. Retrieval runs on every message and nobody established whether a question needs the corpus at all, so an off-corpus question draws a non-sequitur refusal that is stored as a `generated` Turn

**Design:** **Supersedes [ADR-028](../../adr/028-no-tool-calling-in-the-answer-path.md)'s decision** (keeping its four reasons, its evidence table and its three revisit conditions, each assessed: chunk-level retrieval holds · a real corpus only partly, the proxy tier only · an agentic-versus-pipeline comparison does not) and **amends [ADR-034](../../adr/034-ungrounded-answers-as-a-distinct-state.md) §2** (withholding does not affect the route — completing the §Security Impact correction IR-460 applied), **[ADR-026](../../adr/026-conversational-retrieval-and-memory.md) §13** (the decision call sees prior reader questions only; IR-465) and **[ADR-027](../../adr/027-corpus-level-questions.md) §4** (dormant, not satisfied — §5's router is unbuilt; the landscape exception expires at the `on` go/no-go)

**Implementation:** **No code.** One ADR file, `docs/adr/035-ask-iris-decides-whether-it-needs-evidence.md`, plus the index row in `docs/adr/README.md` and a `Proposed amendment` pointer in the Status of ADR-026, ADR-027, ADR-028 and ADR-034 — **none of which changes an accepted Decision**. The decision itself: one no-parameter `search_corpus` tool call (native tool calling, chosen for **option value against IR-462's own recommendation** — the measurement was inconclusive on accuracy and ~1 s worse at p95); a **union** with IR-464's five-rule detector where either half can require evidence and neither can authorize a direct answer alone; **retrieval on any malformed output, timeout, 429 or uncertainty**; the tool is a route signal and is **never executed** — no second retrieval, no passages back, no loop; the application keeps identity, scope, authorization, `visible_to(user)` and ADR-015's disclosure gate; `off` or `shadow` with `on` **rejected as an invalid value**

**Test:** **None — this is a document.** The claims it makes about the tree were each verified 2026-10-06: `apps/ai/evaluation/labels.py` scores record identity + quote containment and **never** the page (so ADR-028's page-precision objection has no instrument); `apps/ai` holds no routing module, no Lens and no corpus-level path (so ADR-027 §4 is dormant); `MODEL_HISTORY_STATES` is one predicate shared by prompt history and embedding eligibility (so §8's per-consumer rule is an addition, not a restatement); `test_outcome_indistinguishable_http.py` holds the response-boundary half of §7

**Evidence:** `docs/adr/` builds no artefact and runs no test. **No code changed, so no suite was re-run for it**; the last recorded `pytest apps/ai` is **1540 passed** (IR-459, 2026-10-06) and nothing here touches it. Markdown links resolved by hand against `docs/adr/` and `backend/apps/ai/`

**Status:** **PROPOSED — NOT ACCEPTED, and not Done.** A human reviewer's approval is an acceptance criterion of IR-461 and has **not** been recorded. **IR-464 and IR-466 are blocked on approval, not on the draft.** Three things are deliberately unresolved and must not be read as settled: ADR-028's third revisit condition (a measured agentic-versus-pipeline comparison) **was not met**; page precision **has no instrument** and the objection is set aside, not answered; and shadowing real reader questions is gated on the provider's request/response **retention** being verified — the no-training terms cover training, not retention. ADR-027 §4's landscape owner must be **named by a person**, never inferred
