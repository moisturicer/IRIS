## IR-675

**Requirement:** An approved download request is a time-limited grant used while signed in; no bearer link is issued

**Design:** Jira IR-675 (spec IR-672); ADR-048; ASVS 4.0.3 items 8.3.1 and 4.1.3

**Implementation:** `GET /records/<id>/download/` asks `download_access` (`apps/records/download_service.py`): exempt or live grant is served and audited, anyone else who can see the record gets a 403 with a `code`. `DownloadRedeemView` and `download_tokens.py` are deleted. The reader's own button is not yet routed here (IR-677), and copies are marked by IR-676

**Test:** `apps/records/test_download_grant.py`; `record-download` in `apps/tests/access/table.py`; migration run on a copy of the dev database

**Evidence:** Passed locally in Docker; see PR

**Status:** **PARTIAL** until IR-677 routes the reader's button through it
