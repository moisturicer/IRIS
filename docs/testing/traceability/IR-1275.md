**Requirements:** none changed status. Documentation only.

`docs/SRS-v2.md` and `docs/SDD-v2.md` describe the MVP as built at commit `c01f0ef1` (main on 2026-11-24, after IR-1322 merged), as thesis deliverables. They were first written at `a46d7fc4` and re-pinned at Ashlee Sean's request. The commit the deployed server runs is not recorded: iris-demo has been off since 2026-11-15, and every screen is a local build. They are derived from `docs/adr/` and the code; where they differ, the ADRs and code win. `docs/SRS.md` and `docs/SDD.md` are untouched, as the v1 record, and CLAUDE.md's freeze still applies to them.

Both keep v1's structure (Ashlee Sean, 2026-11-23):

- **SRS:** every feature entry has its FR-ID line, a use-case diagram, use-case tables, activity diagrams and screens. Figures and tables are numbered inline. v1's references are reprinted, the software interfaces have one table per dependency, and the NFRs take v1's wording with a Validation line.
- **SDD:** every feature has v1's six parts: user interface design, frontend components, backend components, class diagram, sequence diagrams and schema.

Every status line in SRS v2 is copied from `TRACEABILITY.md` at `c01f0ef1`. Between the two pins the matrix only gained ticket rows; no `FR-`/`NFR-` row changed, so no status changed. No row of `TRACEABILITY.md` was changed, and no label was renamed. SRS v2 Appendix A maps v1 IDs to v2 IDs and to the matrix's labels, including the labels the matrix reuses with a different meaning (for example FR-M6-02).
