## IR-1044

**Requirement:** **Revision workflow errors and confirmations appear as dismissible toasts, so a card or dialog never grows because of a message** — follows IR-272 and IR-273; same pattern as IR-1028; no FR- id

**Design:** [ADR-032 §5](../../adr/032-adviser-first-review-and-office-reviewer-pools.md) (the flow itself is unchanged) · Jira IR-1044

**Implementation:** `store/ui.store.ts`: `addToast` takes an optional `persist` flag; a persisting toast stays until X is pressed, every other toast still leaves after 4 seconds. `RequestRevisionDialog`: a refused request is an error toast (persisting) carrying the server's reason and "Your reason is kept."; the typed reason stays in the box. `NewVersionDialog`: a refused submit is a persisting error toast and the dialog does not grow. `PaperViewPage`: a submitted new version is a success toast; the inline confirmation line is gone and the visually hidden `role="status"` announcement stays. The "Submit is held" reason (state, not an error) stays inline and linked by `aria-describedby`.

**Test:** `components/ui/Toast.test.tsx` (default 4-second life; `persist` stays until dismissed) · `paper-view/RequestRevisionDialog.test.tsx` · `paper-view/NewVersionDialog.test.tsx` (each asserts the toast store and that no `role="alert"` remains inside the dialog; both existing assertions on an inline alert were changed on purpose)

**Evidence:** 2026-11-12, worktree: `tsc --noEmit` clean; `eslint` on `store`, `components/ui` and `paper-view` 0 errors (1 warning, the record-load effect's unused directive in `PaperViewPage.tsx`, not introduced here); `npm run test:changed` 68 files, 1,108 tests: 1,107 pass and one `NotesPanel.test.tsx` autosave test failed on each of two loaded runs (a different one each time), while that file passes alone, 12 of 12, and does not import the toast store, so it is read as a load-timing flake; CI is the gate. **Not seen in a browser**: Docker and PostgreSQL are not available on this machine, so the toast over an open dialog was not looked at.

**Status:** **PARTIAL** — implemented and tested in jsdom; not yet seen in a browser, awaiting CI and review
