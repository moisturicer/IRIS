# IR-1054 — One chunking strategy by measurement, with Figure passages

**Affected requirement labels:** none change status. Part of IR-980; recorded as ADR-067's amendment of 2026-11-15.

[Back to the matrix](../TRACEABILITY.md)

**Implementation:**

- **One strategy.** `labeled-structure-v1` is deleted, and so is the override that sent authoritative structure to it (IR-840); every extractor chunks with `structural-markdown-v1`.
- **Figure passages.** `AI_CHUNK_FIGURE_PASSAGES` (on; trial option `figure_passages`): each captioned or described Figure leaves the text flow for a passage of its own. It embeds caption + description, shows the caption and carries the Figure's box. A Figure with neither is skipped.
- **Formulas in structural.** A transcribed formula is shown as LaTeX and embedded with its description per `AI_FORMULA_TEXT_INDEXED` (IR-1102); an untranscribed one stays in its paragraph as its box, never its OCR text. The set hash covers shown and keyword text once a set has Figure passages or transcriptions.
- **Baseline.** `fixed-window` moves to `apps.ai.evaluation.fixed_window`, registered evaluation-only; ingestion raises `EvaluationOnlyStrategy` for it.
- **Tooling.** `manage.py trial_read_unstructured` reads chosen papers with Unstructured into a database copy, storing Figures and formula crops; `--store-media` fills them in from a stored read.

**Tests:** `apps/ai/chunking/tests/test_structural_figure_passages.py` (new), `test_consolidation.py` (changed deliberately: labeled's tests removed or moved to structural; one ingestion strategy; the baseline refused), `test_regions.py` (labeled's skip removed), `test_token_unit_migration.py` (baseline import path), `apps/ai/tests/test_figure_descriptions.py` (changed deliberately: an uncaptioned Figure gains its passage once described), `apps/ai/tests/test_trial_reads.py`.

**Evidence:** 2026-11-15, Windows 11 host. The chunking suite passes, as do the ingestion, figure-description, formula-transcription, keyword-index, chunk-repository, trial, evaluation, retrieval, figure and formula-crop test files, except `test_chunking_is_keyed_on_document_kind.py::test_the_submit_endpoint_marks_what_it_writes`, which fails the same way without these changes (the PDF check sandbox needs Linux). The full suite is left to CI.
Run files `docs/evaluation/runs/2026-11-15-ir1054-{six,full,sweep,hybrid}/` (proxy tier): labeled 0.567 vs structural 0.573 (tie); size sweep keeps 700; Figure passages 0.562 main set, 0.649 slice, 0.759 vs 0.345 on IR-1125's Figure set.

**Not done:** the comparison ran with most formulas and Figures untranscribed (286 of 1,355; 163 of 474). Unstructured's line-end hyphens keep 13 main-set labels from matching (shaping fix, separate). The live corpus has not been re-chunked.

**Status:** Implemented; CI and human review pending.
