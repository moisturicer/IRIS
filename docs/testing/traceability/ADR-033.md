## ADR-033

**Row, as recorded:**

**ADR-033** | **Hybrid retrieval and passage selection** — no FR- id; [ADR-033](../../adr/033-hybrid-retrieval-and-passage-selection.md) (Accepted 2026-09-28, IR-391) is the requirement. Keyword search over the whole visible passage catalogue merged with vector search **by rank position** inside reranking; a database-maintained chunk keyword index; a relevance cut-off applied to **reranker scores only**, absent in degraded mode and never shown to a reader; passage selection (per-paper cap, ignored in Paper Chat · neighbour joining that keeps every region and cites the first page · a token budget in real `voyage-context-4` tokens). Amends [ADR-008](../../adr/008-ai-degradation-to-fts.md) (FTS gains a second job, on the normal path) and [ADR-023](../../adr/023-retrieval-quality-evaluation.md) (labels are `(record, page, quote)`; every run reports retrieval recall **and** recall over the final set sent to the model; one change at a time against a fixed baseline; a manual command, never CI) | **Two of six techniques built, both shipped off.** Every technique lands behind a setting **defaulting to today's behaviour**, and a default moves only on a harness run: IR-393 (keyword index, done), IR-394 (harness, done), **IR-395 (§1's fusion and keyword retrieval, done — `apps/ai/retrieval/fusion.py`, measured at +0.192 recall@10 with reranking on the proxy corpus and still defaulted off)**, IR-396 (nothing-relevant), IR-397 (selection) | See the IR-395 row: `test_fusion.py` (24) plus the enumeration guard | Visibility is unchanged and asserted, not assumed: both searches filter through the single `visible_to(user)` predicate inside retrieval, before scoring or merging, and `test_fusion.py::KeywordPathVisibilityTests` holds the keyword half to it (see NFR-S4) | **PARTLY BUILT** — §1-2 land in IR-395, off by default; §3 and §4 are IR-396 and IR-397; no default moves before IR-402. **Divergence recorded 2026-10-02 (IR-453):** §5's "a default moves only when a run shows the change helps" is **unsatisfiable for §3's cut-off** — both harness measures are recall measures, a floor can only remove passages, and neither committed question set holds a single unanswerable question, so a run can report what a floor costs and never what it buys. **§5 was then amended the same day (IR-453) to exempt §3's cut-off, which now ships ON** — the first and only exemption, granted because §3 is not a recall optimisation like the other five but the precondition for a reader-facing behaviour (ADR-034), so leaving it off deletes that behaviour rather than deferring it, and because a rule that can never be satisfied cannot be what holds a default shut. The reversal's cost is recorded, not softened, against three mandatory safeguards: a deliberately loose provisional default taken from observed reranker scores recorded in the PR (the IR-446 precedent), **IR-454**'s correct-refusal and false-refusal guards, and ADR-034's label shipping in the same change as the behaviour. §5 still governs the other five techniques and IR-402 still owns their defaults. §3 also gains a dependant: [ADR-034](../../adr/034-ungrounded-answers-as-a-distinct-state.md)
