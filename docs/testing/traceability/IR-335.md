## IR-335

**Requirement:** **PDF.js reader with citation highlighting, centred Paper View, markdown overview** — the frontend consumer of IR-334's wire contract

**Design:** [ADR-031](../../adr/031-pdf-citation-overlay.md)

**Implementation:** `frontend/src/lib/pdf.ts` (new) is the one place `pdfjs-dist` is imported — the worker is bundled by Vite (`?url`, resolves to a hashed local asset, never a CDN) and `PaperPdfReader.tsx` (new, lazy-loaded: pdf.js is large and most visits never open the Paper tab) fetches the manuscript through `apiClient` as a blob (never a bare `<a href>`, which 401s against the now-`IsAuthenticated` endpoint), renders each page to its own canvas, and draws `CitationOverlay.tsx` (new) over it from `Region`s positioned as CSS percentages of the page — scale-invariant by construction, so a highlight never needs recomputing on zoom. `PaperViewPage.tsx` gains an alphaxiv-style Abstract/Paper `role="tablist"` toggle and a `max-w-6xl mx-auto` container (the right rail stays alongside the main column, centred as a pair, not moved elsewhere); a citation click carries the live `Citation` — regions included — as router `state` (`citedPage.ts::citationNavigationState`), so the reader draws its highlight with no second fetch, falling back to page-only (no highlight) on any navigation that did not originate the state (a typed URL, a refresh). **The raw `<a href={paperUrl}#page=N}>` link and `paperHrefAtPage` are deleted, not merely replaced** — IR-334 put the manuscript behind `IsAuthenticated`, and a bearer token lives in memory, never a cookie, so a plain anchor built from that path now 401s regardless; `PaperViewPage.test.tsx`'s three citation-arrival tests, written against the old anchor, are rewritten to assert tab-switching and the props handed to a mocked `PaperPdfReader` instead of an `href`. `PaperAiOverview.tsx` reads the new `GET /ai/records/<id>/overview/` cache instead of firing `/ai/ask/` on every mount, and renders through `CitationText` (the same markdown-plus-citation-chip path chat uses) instead of `whitespace-pre-wrap`, so headings/lists/emphasis in a summary render as such

**Test:** `frontend/src/features/records/paper-view/CitationOverlay.test.tsx` (4 — percentage positioning via `parseFloat`/`toBeCloseTo`, not exact string equality, since `(0.3-0.2)*100` is `9.999999999999998` in IEEE 754; one box per region; nothing drawn for an empty list; `aria-hidden`), `PaperPdfReader.test.tsx` (11, pdf.js fully mocked — jsdom has no real canvas 2D context or worker — covering loading/ready/error states, fetching through `apiClient` and never a bare URL, scrolling to the cited page once ready and again on a repeated navigation to the same page via `navKey`, a region drawn only on the page it names, zoom controls, and download-with-no-second-request), `PaperViewPage.test.tsx` (20, `PaperPdfReader` mocked to assert the `scrollToPage`/`highlightRegions` props it receives — arriving with `?page=N` selects the Paper tab and passes the page through; router state carries a citation's regions with no second fetch; no page or an unparseable one stays on Abstract; clicking View Paper switches tabs), `PaperAiOverview.test.tsx` (rewritten — markdown heading rendering, a citation chip linking into the reader at its page, the cache queried by record id not a corpus-wide question, degraded/unavailable/not-indexed states, axe clean), `citedPage.test.ts` (rewritten — `citationNavigationState` wraps both a live and a replayed citation for router state; the three `paperHrefAtPage` tests are deleted with a comment explaining why, not silently dropped)

**Evidence:** `npx tsc --noEmit` clean; `npx eslint src` 0 errors (7 pre-existing warnings, none in touched files); `npm test` 32 files / 255 passed, 0 failed; `npm run build` green — `pdf.worker.min-*.mjs` (1.27 MB) and `PaperPdfReader-*.js` (487 kB / 146 kB gzip) both split out of the main bundle, which dropped from 485 kB to 339 kB gzip

**Status:** **IMPLEMENTED** — no manual verification against a real rendered PDF in a browser (jsdom cannot run pdf.js at all, which is why every test here mocks it); the citation-overlay effort ADR-025 left open is now built end to end in code, not yet eyeballed on a real submission
