# IR-806: Deploy IRIS to a temporary server and seed the validation environment

**Requirements:** no FR- id. Epic IR-805 (S2 Epic: Deployment). Covers ASVS 14.4.5 (`SECURITY_CHECKLIST.md`).

## What exists

- **The server:** `iris-demo` in AWS `ap-southeast-1`, at `https://iris-citu.duckdns.org`, first deployed by hand on 2026-11-10. IR-1013 to IR-1018 record its template, guards, logs and one-command update.
- **Seeding, as changed on 2026-11-11 by Hermoine Zozobrado:** demo accounts only, one per role (`seed_demo --accounts-only`). No papers are seeded; a paper reaches the server through the real Publish and review process. The ticket asked for seeded papers at every workflow stage before this change.
- **HSTS on every response:** `deploy/caddy/Caddyfile` adds `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload` to every HTTPS response. Before this, only Django's responses carried it (`production.py`), so the pages and files nginx serves went without. `defer` sets it after the upstream answers, so a Django response carries one header, not two. The value is `production.py`'s (ADR-057).

## Evidence

- **Checked on iris-demo, 2026-11-11, by Hermoine Zozobrado from a laptop (Git Bash):**
  - `curl -sSI https://iris-citu.duckdns.org/`: `HTTP/1.1 200 OK`.
  - Certificate: `subject=CN=iris-citu.duckdns.org`, `issuer=C=US, O=Let's Encrypt, CN=YE2`, `notAfter=Feb  8 12:30:22 2027 GMT`.
  - `/media/test.pdf`: `200` with `Content-Type: text/html`. That is the app's page from nginx's fallback, not a file: nginx has no `/media/` location (IR-152).
  - HSTS: **none** on the home page. That is the gap the Caddyfile change closes.
- **Demo passwords:** Hermoine Zozobrado reports the demo accounts on iris-demo no longer use `seed_demo`'s published password. Not checked here.
- **CI:** the "Caddy serves HTTPS only, with strong TLS and HSTS" step runs the real Caddy and Caddyfile and requires exactly one HSTS header with that value, both where the upstream sends none (as nginx) and where it sends its own (as Django, under `/api/`). Not run locally: this session has no Docker daemon and couldn't fetch Caddy.
