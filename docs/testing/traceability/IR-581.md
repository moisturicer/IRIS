# IR-581: Ask about a text selection

**Requirements:** IR-553 User Stories 14–16, ADR-049 (AI-owned runs), ADR-065 §8 (the shared selection menu). The matrix has no `FR-` row for this.

## What changed

**Page.** The paper's selection menu (ADR-065 §8, built by IR-583) gains *Ask about selection* wherever Ask IRIS is offered. It opens Paper Chat with a chip naming the paper, the Manuscript version and the page, over an editable question ("What does this passage mean?" when the box is empty). Nothing is sent until Send, and the chip can be removed first. A question asked about a passage replays it above the question, or says it is no longer available.

**Runtime.** `POST /api/v1/ai/runs` takes an optional `selection` `{record_id, manuscript_revision, page, quote}`; `manuscript_revision` may be null. **Nothing about the passage is refused.** The owner decided on 2026-11-19 that the model, not the server, should judge a selection that does not match. Only a malformed shape (`422 invalid_selection`) or a runtime on a pin before research-12 (`422 selection_unsupported`) is refused.

The selection is part of the request identity. It is stored on the run (migration `0021`), copied by a retry and onto the Turn, and cleared when the Conversation is deleted. Just before the model is called, the worker checks it under the grant the run holds now (`ai/runs/anchor.py`, `assess`):

- **The paper must be readable by this reader and indexed.** Visibility, the disclosure gate and a Paper Chat scope are PostgreSQL's (`iris_ai.research_source_revision`, `research_chunks()`). Otherwise the quote never reaches the model, which is told only that the selection could not be used (`SELECTION_WITHDRAWN`).
- **Otherwise it is sent, with what was found.** The model gets `[IRIS selection] {paper, page, quote, found_on_page, version}`: whether the quote starts on that page of the text it can read, and whether it was selected on the same version, a different one, or one the page did not name. research-12's instructions tell it to find the passage itself (nearby pages, `read_manuscript`, `search`), to cite only what it read, and to say so if it cannot find it. A selection from another readable paper names that paper.

The quote is compared on its letters and digits in order, ignoring case, spacing and punctuation, because the PDF's text layer and the indexed text disagree on them ("ad-dresses" against "addresses"). A "." or "," inside a number is kept. On a dev paper this matched 87% of real page-text windows (58% before); the rest cross a footnote the extraction moved.

## Limits and decisions for review

- **Departs from the ticket.** The ticket says a tampered or older-version selection "is refused". At the owner's direction it is asked, and the model is told what did not match. What protects answers is unchanged: a citation binds only to a passage the run read.
- **Page precision is a chunk's.** The chunk that runs onto page N counts for page N.
- **A new pin, `research-12`** (ADR-049 amendment of 2026-11-19): research-11 plus one paragraph on selections, the default for new runs. Only research-12 is sent a selection. research-11 keeps its recorded digest. The effect on answer quality is not measured.
- **The model reads only the indexed version.** "Recheck the version" means looking for the passage in the version IRIS has read; an earlier version's bytes are not indexed.

## Verified

`test_ai_runtime_selection_db.py` (12 tests) passed locally against PostgreSQL on 2026-11-19, along with the contract and page tests. Migration `0021` was applied to a local dev database; it was not rehearsed on a copy of a realistic one. Production use with real CIT-U papers also needs IR-250.
