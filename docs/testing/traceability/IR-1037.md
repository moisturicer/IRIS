# IR-1037: A guard fails the build on new arbitrary font sizes

**Requirement:** `docs/frontend_redesign_spec.md` section 4.12 (type scale, "never below 12 px"); IR-452 (named type scale); IR-358 (palette guard pattern)

`src/test/fontSize.test.ts` scans every non-test `.ts` and `.tsx` file under `frontend/src` and rejects an arbitrary font size (`text-[` then a number and `px` or `rem`). The sizes already in the code are recorded per file in `src/test/fontSizeAllowance.ts`: 268 uses, 236 at 12 px or more in 63 files and 32 below 12 px in 19 files (67 files in all). The two groups are checked separately.

A file may use fewer than its allowance, never more, and a file not listed may use none. When a file's count drops, the test fails until the allowance is lowered, so the list only shrinks. A failure names the file, the class and the nearest type role.

No file was migrated; that is IR-1038 and IR-1039 to IR-1042.

Executed evidence (2026-11-12):

- GREEN: `src/test/fontSize.test.ts` 9 / 9.
- Regression proof, each reverted afterwards (`git status` clean):
  - a throwaway `text-[14px]` in `StatusBadge.tsx` (not listed) failed the guard: `StatusBadge.tsx: 1 found, 0 allowed ... (text-[14px] -> text-body)`;
  - a throwaway `text-[10px]` in the same file failed the separate 12 px floor assertion: `... Use text-label. (text-[10px] -> text-label (12 px, the floor))`;
  - replacing the one `text-[14px]` in `LoginForm.tsx` without lowering its allowance failed the ratchet: `LoginForm.tsx: 0 found, 1 allowed. Good, now remove its entry`.
- `npm run test:changed`: 7 files / 85 tests passed. The full suite, type-check, lint and build are left to CI.

Counting note: the ticket quoted 263 uses in 65 files. That came from a line count over `.tsx` only. The guard counts matches and also reads `.ts`, which adds `components/ui/fieldClasses.ts` (3) and `features/discover/discoverUtils.ts` (1). Of the 32 below 12 px, `discoverUtils.ts` also sets uppercase with tracking, which section 4.12 rules out.

Overlap: `features/records/paper-view/readingStandards.test.ts` already holds a name-only version of this rule for six dialog files. It was left unchanged. Those six files must be removed from both lists when IR-1042 migrates them.

`docs/ui-ux/01-design-system.md` section 0 gains a "Font-size guard" row.
