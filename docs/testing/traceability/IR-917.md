# IR-917: hostile-content render tests for AI text, passages and file names

[Back to the matrix](../TRACEABILITY.md)

**Requirements:** no requirement row changes. This adds tests for the frontend's untrusted-text surfaces (IR-900, threat model IR-617) and fixes two defects they found. Server-side sanitisation and CSP enforcement (IR-823) are out of scope.

**Surfaces.** `grep` for `dangerouslySetInnerHTML`, `react-markdown` and `innerHTML` in `frontend/src` (2026-11-06) finds exactly two renderers of untrusted markup, and every other place that shows a manuscript passage, comment or file name writes a React text node.

| Surface | Untrusted input | How it renders |
|---|---|---|
| `CitationText` (AI answers, AI Overview) | model output built from manuscripts | `react-markdown`, no `rehype-raw`, KaTeX via `rehype-katex` (`trust` off), `urlTransform` defers to the library |
| `PassageQuote` (chat, sources panel, overview) | manuscript text | text nodes, plus KaTeX HTML from `katex.renderToString` through `dangerouslySetInnerHTML` |
| `UploadDropzone` | the uploaded file's name | text node and `aria-label` |

**Defects found and fixed**

1. **A `javascript:` or `data:` link kept a live anchor.** `react-markdown` blanks the refused `href`, but `CitationLink` still rendered `<a href="" target="_blank">`, a link back to this page in a new tab. It now renders the words as a `<span>` (`CitationText.tsx`).
2. **Oversized or deeply nested formulas froze or crashed the page.** Measured in Node, KaTeX took about 0.3 s for 5,000 terms and about 5 s for 20,000, on the main thread. About 2,000 nested braces throw a stack overflow, which `throwOnError: false` does not cover, so in `PassageQuote` (which calls KaTeX directly) it would have thrown out of render. A formula over 2,000 characters is now shown as source (`mathLimit.ts`: `MAX_FORMULA_CHARS`, a remark plugin for answers and a length check in `PassageQuote`), and `PassageQuote` catches a KaTeX exception and shows the source. The cap is a judgement call: no real formula nears it, and it is one constant.

**Observed, not fixed here; fixed by [IR-930](IR-930.md).** `remark-gfm`'s email autolink is quadratic on a very long run of `a+a+a+…` text (about 2 s at 40,000 characters, measured in Node). It is not specific to this code, answers are length-limited by the model, and a fix would mean replacing or patching a dependency. The oversized-formula test uses a body without `+` so it does not measure the parser.

**What proves it**

| Check | Where |
|---|---|
| Raw HTML (`<script>`, `<img onerror>`, iframe, svg, object, form, style, meta, handlers) in an answer renders as inert text; entity-encoded markup is not decoded into elements | `CitationText.hostile.test.tsx` |
| `javascript:` (mixed case, encoded colon, tab, leading space), `data:`, `vbscript:`, `file:`, `blob:` links, reference links and autolinks lose their `href`, keep their words, and execute nothing; an `https` link keeps `target="_blank"` and `noreferrer` | same |
| A forged `iris-citation:` link cannot make a chip without a citation or point one at another paper; a hostile record title stays in an attribute | same |
| Markup in a streamed citation-shaped span, in a code span and in a fenced block stays text | same |
| `\href`, `\url`, `\htmlId`, `\htmlClass`, `\htmlStyle`, `\htmlData`, `\includegraphics` in a formula make no link, id, class, data attribute or handler; injected HTML inside a formula stays text; malformed, nested, oversized and macro-bomb formulas fall back and keep the surrounding prose | same, and `PassageQuote.hostile.test.tsx` |
| Script, image, svg, anchor and iframe markup in a passage is literal text; markdown link syntax is not turned into a link; hostile `title` text stays an attribute value | `PassageQuote.hostile.test.tsx` |
| A file name carrying markup is shown as text in the refusal, the uploading line and the failed state | `UploadDropzone.hostile.test.tsx` |

The shared assertion (`src/test/hostile.ts`, `expectInert`) walks the rendered subtree and fails on an executable or embedding element, any `on*` attribute, a URL attribute on `javascript:`/`data:`/`vbscript:`/`file:`/`blob:` or on any scheme but `http(s)`, `mailto`, `tel` or a relative URL, and an inline style carrying `url(` or `expression(`. KaTeX's own `svg` is allowed only in the formula tests.

**Run, and not run (2026-11-06).** See the PR for the local run and CI result. jsdom does not execute scripts or load images, so "nothing executes" is shown by the absence of the element or handler and by a `window.__pwned` flag that stays unset, not by observing a browser. Colour contrast and CSP behaviour are not covered.
