## ADR-034

**Requirement:** **An ungrounded answer is a distinct state, never a grounded one** — no FR- id; [ADR-034](../../adr/034-ungrounded-answers-as-a-distinct-state.md) (Accepted 2026-10-02, IR-453) is the requirement. A new `Turn.state` `ungrounded`, reachable **only** when [ADR-033](../../adr/033-hybrid-retrieval-and-passage-selection.md) §3's relevance cut-off leaves zero passages; `GROUNDING_RULES` unchanged and a separate prompt with no `Sources:` block; no citations and no Record cards, ever; a visible not-from-the-repository label; **no research question may reach it** and a zero-source research question stays a refusal; excluded from the model's history; **ON by default** — amending ADR-033 §5, which exempts the cut-off from its off-by-default rule — and absent in degraded mode. **The not-from-the-repository label ships in the same change as the behaviour**, because with both defaults on a floor without a label is a window in which an ungrounded answer is indistinguishable from a cited finding

**Design:** Amends [ADR-008](../../adr/008-ai-degradation-to-fts.md) (*never a fabricated answer* is kept and given an explicit boundary — fabrication is a grounded answer that is not grounded) · [ADR-026](../../adr/026-conversational-retrieval-and-memory.md) §13 (`ungrounded` joins the excluded states; `MODEL_HISTORY_STATES` stays `{generated}`) · [ADR-027](../../adr/027-corpus-level-questions.md) §4 (an absolute bound: the Lens computes and the model only reports, so no landscape or corpus-level question goes ungrounded) · depends on ADR-033 §3

**Implementation:** **NOT BUILT.** No code yet. The gap this records is verified in code 2026-10-02: `apps/ai/retrieval/two_stage.py` ends in `.order_by(distance)[:limit]` with no relevance floor, so an off-corpus question retrieves its top *k* anyway, meets `GROUNDING_RULES` in `apps/ai/answers/citations.py`, and the model's own refusal is stored as `generated` — so `MODEL_HISTORY_STATES = frozenset({GENERATED})` (`apps/ai/models/conversation.py`) does **not** exclude it and IR-448 does not reach it. IR-396 builds the floor; this state is IR-453

**Test:** **None yet.** When built: a research question must refuse rather than answer from model knowledge (IR-453's AC, and the test ADR-027 §4 as amended demands); a zero-source question whose passages were withheld by the disclosure gate must be `no_sources` and never `ungrounded` (see NFR-S4 — the inverse would signal that relevant-but-unreadable material exists); the state must be absent in degraded mode; `MODEL_HISTORY_STATES` must still be `{generated}`

**Evidence:** **Verified in code 2026-10-02 (IR-453), not asserted:** driving `POST /api/v1/ai/ask/` against a two-paper corpus retrieved two irrelevant papers, both reached the prompt under `Sources:`, and the resulting model-written refusal was stored `generated`. Both committed question sets were checked for calibration material and **neither holds a single unanswerable question** — `apps/ai/evaluation/fixtures/synthetic_set.json` (2) and `docs/evaluation/proxy_starter.json` (52) are all labelled, which is why ADR-033 §5's gating rule cannot be satisfied for §3's cut-off and why that is recorded as a divergence in ADR-033 rather than reconciled

**Status:** **ACCEPTED, NOT BUILT.** **Reachable as soon as IR-396 lands** (revised 2026-10-02): ADR-033 §5 was amended to exempt §3's cut-off from the off-by-default rule, because leaving the cut-off off would not defer this behaviour to IR-402 — nothing can branch on a zero-source condition that never occurs — it would delete it. **IR-402 no longer gates this**; it keeps §5's other five defaults. The trade is recorded rather than softened: the floor is switched on with no run able to show it helps, against three mandatory safeguards (a deliberately loose provisional default, IR-454's correct-refusal and false-refusal guards, and the label shipping with the behaviour). **Known limitation, recorded not fixed:** in degraded mode there is no reranker, so no cut-off, so the `generated`-refusal history gap persists there; closing it needs a signal degraded mode does not have and one is deliberately not invented (ADR-008 §Amendment — IR-391)
