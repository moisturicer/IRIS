# IR-1258: Publish opens over the page you are on

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** opening a draft from My Library (*Continue draft*, the draft's title, or *Publish*) keeps My Library behind the Publish form and current in the sidebar, and closing the form leaves the reader on the same tab. Reported by Hermoine Zozobrado on 2026-11-21. No FR- id.

**Design:** no ADR change. IR-408 made Publish a dialog opened by `?publish=`, and mounted it on the home route only, so every link to it was `/?publish=<id>`: the page behind it became Discover. This keeps the dialog and its parameter and moves where it is mounted. [IR-1227](IR-1227.md)'s rule is unchanged: a draft has no paper page, and opening one opens Publish.

## What changed

- **One dialog for the app** (`AppShell.tsx`, `HomePage.tsx`): `PublishDialog` is mounted once in the shell, after the page, so `?publish=` opens it over any page. Discover no longer mounts its own.
- **Links keep the page** (`publishLink.ts`): `publishHref` / `usePublishHref` add `publish=<id>` to the current address and keep its query, for example `/records/mine?section=research&publish=12`. Closing already removed only `publish`. Used by My Library's *Publish* buttons and *Continue draft*, *Continue proposal* (`ContinueProposal.tsx`, which opens over the record page it was chosen on) and the *Resume draft* links inside the form (`ManuscriptStep.tsx`, `ReviewStep.tsx`).
- **A draft's title** (`SubmissionRow.tsx`): opens Publish over My Library directly, as *Continue draft* does. It no longer goes through `/records/<id>`.
- **A draft's address** (`PaperViewPage.tsx`): `/records/<draft id>` now redirects to `/records/mine?publish=<id>`, over My Library, where the draft lives, instead of over Discover.
- **My Library reads its papers again when the form closes** (`MyLibraryPage.tsx`). This happens quietly, with no spinner, so a draft edited, submitted or deleted in the form shows at once.
- **Unchanged:** Discover's own *Publish* already set the parameter on its current address. The retired `/records/add` redirect still lands on `/?publish=new`.

## Tests

**PARTIAL.** These ran locally on 2026-11-21. CI and a person's review are still to come.

| Test | Shows |
|---|---|
| `AppShell.test.tsx` › *opens Publish over the page it is on…* | `?publish=` on `/records/mine` opens the dialog with My Library's heading still there and My Library, not Discover, current in the sidebar. Closing leaves `/records/mine?section=saved` |
| `PublishDialog.test.tsx` › *leaves the reader on the page it opened over…* | Closing a draft with *Keep as draft* leaves `/records/mine?section=research` |
| `MyLibraryPage.test.tsx` › *opens Publish over the tab it is on…* | Every *Publish* link is `/records/mine?section=research&publish=new` |
| `MyLibraryPage.test.tsx` › *reads its papers again, without a spinner, when Publish closes over it* | Removing `publish` reads `/records/mine/` again, a deleted draft leaves the list, and the tab stays |
| `ContinueProposal.test.tsx` › *opens Publish over the page it was chosen on* | From `/records/12?section=overview`, the new draft opens at `/records/12?section=overview&publish=42` |
| `PaperViewPage.test.tsx` › *sends the owner opening a draft by …* | Both a draft's address and an old Review link land on `/records/mine?publish=<id>` |

**Tests changed deliberately:**
- Three `MyLibraryPage` tests expected *Continue draft* at `/?publish=12` and the draft's title at `/records/12`. Both now expect the My Library address. The Overview test now renders at `/records/mine`, so that address is the one it checks.
- The two `PaperViewPage` draft-redirect tests expected `/?publish=<id>` and now expect `/records/mine?publish=<id>`.

**Checks run:** `npx tsc --noEmit` and `npm run lint` passed (0 errors; the 2 warnings are in files this change does not touch). The affected folders passed: 27 files, 849 tests. The full `npm test` passed 3,711 of 3,715 (3 skipped). The one failure was a different test on each run, in files this change does not touch (`PublishDialog` › *documents* on one run, `MyTemplatesPage` on the next), and each passes alone.
