## IR-1212

**Requirement:** **The review page's Conversation tab opens with who submitted the paper and when, and nothing more.** No FR- id; reported in team testing, 2026-11-17.

**Cause:** the Conversation tab's first box (`SubmissionBox` in `ReviewTimeline.tsx`) was built like a pull request's description. It showed the submitter and date, then the record's abstract, clamped to three lines. The Overview already shows the abstract in full, so the copy here only pushed the discussion down.

**Implementation:**
- `TimelineSubmission` no longer has an `abstract` field, and `ReviewWorkspaceLayout.tsx` no longer passes `record.abstract`. The type now keeps it from coming back.
- The box reads "Ana Cruz submitted on Sep 1, 2026". The name is in bold, as the other entries name their author ("Ana Cruz sent v2"). With no name from the server it reads "Submitted on Sep 1, 2026", and with no date, "Submitted". The box's accessible name follows the same rule: "Submission by Ana Cruz", or just "Submission" with no name, so it no longer names "The authors" when the text names no one.
- The line used to read "Ana Cruz submitted v1 · Sep 1, 2026". It no longer says "v1": the ticket asks for "Submitted on <date>" alone, and the first box is always v1.
- The unused `.review-abstract` rule is removed from `reviewWorkspace.css`.
- The Overview's abstract is untouched.

**Test:** `ReviewTimeline.test.tsx` has two new tests:
- With a submitter: the box, named "Submission by Rhea Owner", reads exactly "Rhea Owner submitted on Sep 1, 2026", and axe passes.
- With no submitter named: the box, named "Submission", reads exactly "Submitted on Sep 1, 2026".

The box was covered by no test before this ticket.

**Review:** a standards and a spec review found the accessible name still said "Submission by The authors" when the text named no one; fixed, and the test now checks the name. They also asked that dropping "v1" be stated, which it now is above.

**Evidence:** 2026-11-18, local.
- Before the change, both new tests failed on the box's text.
- After it, `ReviewTimeline.test.tsx` and `ReviewWorkspace.test.tsx` pass, 27 of 27. The `features/records` tests pass, 59 files and 1037 tests.
- `tsc` is clean.
- `eslint` on `paper-view` reports one warning, already on `main`, in `PaperViewPage.tsx`, which this change does not touch.

**Status:** **IMPLEMENTED**; awaiting CI and review.
