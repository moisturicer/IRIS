## IR-579

**Requirement:** **Old browser-only library storage is retired** — no FR- id; subtask 3 of IR-553 (User Stories 4–7)

**Design:** [ADR-044](../../adr/044-account-backed-research-library.md) §Amendment 2026-11-16 (IR-579) (decided by Hermoine Zozobrado on 2026-11-16, **accepted** the same day by Lee Jasmin Adolfo, as relayed by Hermoine Zozobrado). It replaces the import IR-579's card describes: IRIS has had no readers, so the only browsers holding `iris_record_collections` and `iris_starred_records` are development and test machines, and the keys are deleted instead of imported. The card's import criteria (preview, selection, import identity, retry tests) are therefore not built; the card's acceptance criteria were replaced with matching ones on 2026-11-16.

**Implementation:** `frontend/src/lib/recordLibrary.ts`: `clearReadingHistory()` becomes `clearOldBrowserLibrary()`, which deletes `iris_reading_history`, `iris_record_collections` and `iris_starred_records`. `store/auth.store.ts` calls it on sign-in, sign-out (`logout`) and session end (`clearTokens`), as it did for history since IR-756. No code reads or writes the keys; the browser-only save and folder code itself was already deleted by IR-566 and IR-572. No backend change, no migration. ADR-044 (§7, Q1, Decision Rationale) and ADR-070 (§7, Consequences) carry notes pointing at the amendment; PRODUCT.md and the ADR index say the keys are deleted, not imported.

**Test:** `lib/authStorage.test.ts`: "sign-in deletes what an older build kept of the library in this browser" (new); "logout leaves nothing behind", "clearTokens, the session-end path, leaves nothing behind either" and "a rotated refresh token is cleared too" now seed all three keys, including a status folder, an own folder and a star, and assert each gone. `MyLibraryPage.test.tsx`: "never shows the old browser saves, folders and stars, and signing out deletes them (IR-579)" — the old data is not shown, nothing is saved or created from it, and sign-out removes both keys.

**Deliberate test changes:** `MyLibraryPage.test.tsx`'s "leaves the old browser saves, folders and stars untouched for the import (IR-579)" asserted the keys stayed byte-for-byte; it now asserts they are never shown and are deleted at sign-out. `authStorage.test.ts`'s "leaves storage that is not a credential alone" used `iris_record_collections` as its example of non-credential storage, which the auth store now deletes; Discover's `iris.discover.columns` stands in.

**Evidence:** 2026-11-16, local: `npm test` **223 files, 3204 passed** (3 skipped); `npm run test:changed` 90 files, 1769 passed; `tsc --noEmit` clean; `eslint` clean on every changed file; `npm run build` succeeds. No backend file changed. CI runs on the PR.

**Status:** **IMPLEMENTED** with local test evidence; awaiting CI, review, and acceptance of the ADR-044 amendment.
