# IR-1355: ITSO handles IP and patents; KTTO and TBI handle commercialization

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** Hermoine Zozobrado decided this on 2026-11-28. There is no FR- id. [ADR-068](../../adr/068-tbi-is-a-specialist-office.md)'s amendment of 2026-11-28 holds the decision. It was accepted by Ashlee Sean with PR #1041's merge on 2026-11-28, as relayed by Hermoine Zozobrado. It also amends [ADR-052](../../adr/052-each-paper-states-its-embargo-and-a-person-ends-it.md) §11–12, restores [ADR-018](../../adr/018-conditional-parallel-office-routing.md)'s office table for ITSO, and supersedes [ADR-066](../../adr/066-ip-applications-beside-publishing.md).

- **ITSO** handles IP and patents: protectability, prior art, and whether to file.
- **KTTO and TBI** handle commercialization, as one shared step with the same papers, as in IPAMS. TBI is not built yet.
- **IP stays in the main paper flow.** No separate applications (ADR-066 superseded; IR-978, IR-1058 to IR-1065 and IR-979 closed). The in-flow IP status is IR-1356.
- **ITSO alone releases an IP mark for the AI** (Hermoine Zozobrado, 2026-11-28, while building this ticket).

This replaces the office meanings recorded on 2026-11-01 in [IR-767](IR-767.md) ("ITSO handles technical review, KTTO evaluates IP submissions"). That file is kept as history. Supporting evidence from IPAMS (`moisturicer/IPAMS`):
- its flow is Student → Adviser → "KTTO / TBI" → RDCO, with KTTO and TBI sharing the same records;
- its manual says ITSO mainly reviews the submitted documents, which include the patent, utility model, trademark and copyright filings.

## Design

- `apps/reviews/routing.py` `_AUTHOR_FLAGS`: `is_ip` hints at ITSO; `for_commercialization` still hints at KTTO. The hint text is unchanged.
- `core/permissions.may_release_ip`: ITSO, not KTTO. `ip_release.py` messages and the view docstrings say ITSO.
- `Record.ip_released_at`'s help text says ITSO (migration `records/0045_ip_release_is_itsos`, help text only).
- Access matrix `RELEASES_IP`: the three ITSO columns are allowed; the world's paper is unmarked, so they are answered 400, which counts as allowed.
- Comments in the AI disclosure policy and the audit model say ITSO; `AUDIT_EXPORT.md` and the IR-858 publication notes follow.
- **Screens:**
  - "About this record" reads *Released for the AI*, naming no office: KTTO released marks before this change, so a fixed office name would misreport those.
  - Help's workflow section says RDCO can ask *ITSO to review intellectual property and patents*.
- `seed_demo`: KTTO's reason ("Commercialisation review.") already matched. ITSO's routing reasons and review comments said "technical review"; they now ask about IP and patentability (for example, "IP review complete; nothing to file before publishing.").
- **Docs:**
  - the ADR index rows for 052, 066 and 068;
  - ADR-063's note on the IP application flow;
  - the proposed privacy and terms notes.
  - Older architecture-review and UI/UX notes that call ITSO "technical" are dated analyses and are left as they were.
