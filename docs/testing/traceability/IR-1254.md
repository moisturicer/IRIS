# IR-1254: Request documents lives only on the Documents tab

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** a reviewer asks the owner for documents from the Review pane's Documents tab only, not from the review footer or its *More review actions* (⋯) menu. The Documents tab offers it to exactly the viewers the footer did (`can_request_document`). [ADR-032](../../adr/032-adviser-first-review-and-office-reviewer-pools.md), *Amendment, 2026-11-21 (IR-1254)*, decided by Hermoine Zozobrado: documents-related actions stay on the Documents tab. No FR- id.

## What changed

- **One footer list** (`reviewActions.tsx`): `REVIEWER_FOOTER_ACTIONS` is what a reviewer's footer may offer. It leaves out *Request review* (the Reviewers list's, IR-685) and now *Request documents*. `ReviewWorkspaceLayout` uses it, and so do `ReviewFooterActions`' tests, which kept their own copy of the list before.
- **Unchanged:** the Documents tab's *Request documents* button and *Documents you requested* list (`ReviewerDocumentRequests`), the dialog itself, and the author's footer (IR-1206), which lists its own acts.
- **A reviewer granted only Request documents** now has no footer actions at all, rather than a footer whose one button was Request documents.

## Tests

| Test | Shows |
|---|---|
| `ReviewFooterActions.test.tsx` › *never offers Request documents, and draws nothing when that is all that was granted* | An office reviewer's ⋯ menu has no Request documents; a viewer granted only it gets no footer |
| `PaperViewPage.test.tsx` › *offers a party that may ask but not decide Request documents on the Documents tab, and no footer* | The one Request documents button is in the Documents tab; there is no footer toolbar |
| `PaperViewPage.test.tsx` › *keeps Request documents out of the footer for a reviewer with another act* | The footer shows only Withdraw revision request |
| `PaperViewPage.test.tsx` › *requests documents from the Documents tab and re-reads the timeline after*, *falls to the same not-available state…* | Unchanged tests, now passing through the Documents tab's button: the request is sent and the timeline re-read |

Both new page tests fail on the code before the change and pass after.

**Tests changed deliberately**, each marked IR-1254 in the code:
- Two page tests found Request documents in the footer, and are replaced by the two above.
- In `ReviewFooterActions.test.tsx`, RDCO's and an office reviewer's menus no longer list Request documents.
- Two tests that used Request documents as a stand-in act now use Withdraw revision request.

Run locally on 2026-11-21: `ReviewFooterActions.test.tsx` 11 passed; `PaperViewPage.test.tsx` and `ReviewWorkspace.test.tsx` all passed; `tsc --noEmit` clean.
