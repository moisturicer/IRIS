# IR-851 — LlamaParse acceptance check on the proxy corpus

**Affected requirement labels:** FR-M3-01 (PDF text extraction). Its matrix status does not change: Docling stays the configured Extractor until IR-842.

[Back to the matrix](../TRACEABILITY.md)

**Change:** `request_options()` in `apps/ai/extraction/llamaparse_client.py`, and the recorder's copy, no longer send `confidence_score_effort: "high"`, which costs 5 credits a page. `disable_cache` stays set. Both are recorded in ADR-056's amendment of 2026-11-03, which also runs decision 14's check on six papers rather than forty.

**Test:** `apps/ai/extraction/tests/test_llamaparse_client.py::test_the_request_asks_for_everything_but_paid_confidence_and_times_out_by_page_count` and `test_record_llamaparse.py::test_a_recording_sends_adr_056s_request_and_deletes_the_upload` pin the request. The contract suite runs against IR-841's recordings in the same module.

**Executed 2026-11-03** at `97b71b16`, in a Linux container from the backend image against a fresh test database: 5,876 passed, 1 failed, 17 skipped, 1 xfailed. The failure was Hypothesis's `too_slow` health check on `test_chunker_core.py::test_property_token_ceiling_is_a_guarantee[fixed-window]`, in code this change does not touch. It passed when rerun alone. On the Windows host the same suite cannot pass, because PDF intake needs Linux `RLIMIT_AS` (IR-830).

**Evidence:** [`docs/evaluation/runs/20261103-ir851-llamaparse-six/report.md`](../../evaluation/runs/20261103-ir851-llamaparse-six/report.md). Six proxy papers through the admitted, gated path: 1,731 credits for 78 pages ($2.16). Formulas arrive as LaTeX and no words are broken. recall@10 is 0.929 with reranking for both Extractors; without it LlamaParse is one question below Docling (0.571 against 0.643), so that criterion fails narrowly. `check_vector_index` reads 1.000. **Heading levels fail**: 27 of 113 numbered headings are at the wrong depth, and 11 captions came back as headings. Proxy tier only (ADR-023).

**Open:**
- the project owner's cost acceptance in Jira

- the contract suite on output from the new request (it ran on IR-841's recordings only)
- the heading-level rule
- admission's 508-minute lease and its 13-credit reserve, both under-sized for LlamaParse (report, "Defects found")
