## IR-1057 · Unstructured shaping part B: heading depth, printed pages and line boxes from PDF evidence (ADR-067 decisions 5–7)

`shape_unstructured(raw, pdf_evidence)` now reads the evidence IR-1053 stores.
The rules are in `apps/ai/extraction/evidence_rules.py`, which is pure.

| Rule | What it does |
|---|---|
| Heading depth | First answer wins: bookmark, contents entry, numbering, font (size then bold, only when headings use two or more styles), known thesis heading (top level), `parent_id`, then nesting under the open section. The deciding signal is stored as `DocumentElement.level_source`. The first unnumbered heading on page 1 stays the title at level 1. |
| Printed page | PDF page labels, then `PageNumber` and `Footer` text, then gaps filled between two arabic numbers whose spacing matches. |
| Citation box | An element's box narrows to one box per text line when the stored words inside it spell its text. On a failed match, or a page with no text layer, it keeps the element box. |

`parent_id` comes after known headings because the ADR's amendment ranks it
below the PDF's own signals until IR-989 measures it.
