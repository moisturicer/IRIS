# IR-847: production serves HTTPS through Caddy

**Requirements:** NFR-S1, NFR-S3

Caddy terminates TLS and nginx is no longer published (ADR-056). `apps/tests/test_tls_topology.py` pins what is published, and CI's Docker Compose job runs the real Caddy: plain HTTP redirects, forged forwarded headers are replaced, TLS 1.2 and 1.3 are accepted, and older protocols and weak ciphers are refused.

**Not proven:** a real certificate on a real domain, renewal, or the whole stack behind Caddy. Those need a deployment (IR-806). `NFR-S1` stays PARTIAL.
