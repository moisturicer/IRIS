## IR-1004 — Close the runtime agent's gap on F12 (two readers with different access)

**Basis and scope.** IR-1004 under IR-955; authority ADR-049 and its 2026-11-09 amendment (IR-957). IR-995's paid run 9 (`docs/evaluation/runs/20261109-041415-IR-956-answer-quality-858559d8`) scored the agent 43.8% correct on F12 against Django's 62.5%. Spending for the reruns approved by Jive Tyler I. Revalde in chat on 2026-11-10, under campaign `ir861-dev-pilot-2026-11`.

**What changed (`agent-research-8` / `research-8`, the new default pin).**
- `ai/agent/executor.py`: `EVIDENCE_INSTRUCTIONS` adds to research-7's prompt: answer a question about what a repository paper reports only from what the tools returned; counts and lists from `count_records`/`list_records` count as findings; search again before declining; when the papers this reader can see do not answer it, say so and stop, with no general knowledge and no unread papers, tools or values; never mention an earlier draft.
- F12-04's failure mode (no draft survives, so the run ends `invalid_draft`) is gone on `main` since IR-957: out of repairs, the last draft is delivered whole with unbound citations removed (`assurance.qualified`, or `UNESTABLISHED`). research-8 adds nothing there. An earlier draft of this change added a fixed decline for it; that was dropped when the branch was brought up to date with IR-957.
- `ai/agent/assurance.py`: `feedback(found, unseen=True)` adds `UNSEEN_DRAFT` to research-8's repair note.
- `ai/runs/agent_profile.py`: new runs pin `agent-research-8`. research-8 offers research-7's tools; earlier pins keep their behaviour.
