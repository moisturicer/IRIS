## IR-1287

**Requirement:** On an open paper page, the Review & Routing tracker, the review timeline, the documents tab and the response letter show another person's workflow or document change without a reload. The change is told only to people `may_read_review` admits, once per act. An unsubmitted draft's changes reach only its creator. Public comments catch up when the tab is shown again.

**Design:** [ADR-073](../../adr/073-live-updates-by-server-sent-hints.md) §Amendment 2026-11-23, extended by IR-1287. **Proposed**, not yet accepted.

**Depends on:** IR-1284 (`review_changed`); this PR stacks on [#970](https://github.com/moisturicer/IRIS/pull/970).

**Implementation:**

- **Backend, `apps/live/signals.py`:**
  - `_RECORD_OF` maps 15 workflow and document models to their record. `post_save` on each (and `post_delete` on uploads and files) calls `review_changed`.
  - `review_changed` now sends once per act: each call takes a newer per-thread token, and only the send holding the newest token publishes.
  - `_review_readers` drops anyone `hides_draft` refuses.
- **Frontend**, each through `useLiveRefresh([record:<id>])`, which also fires on reconnect and focus. A failed live read keeps what is shown and shows no error.
  - `ReviewRoutingTracker` and `ReviewTimeline`: quiet tracker re-read, with no skeleton.
  - `DocumentsTab`: `load(true)`.
  - `useNewestResponseLetter`.
  - `CommentsSection`: `refresh(true, true)`.

**Test:**

- `backend/apps/live/test_paper_hints.py` (4):
  - a file added tells the review's readers and no outsider or role;
  - a file removed tells them too;
  - routing tells each reader exactly once;
  - a draft tells only its creator, never a co-owner.
- `frontend/src/features/records/paper-view/ReviewRoutingTracker.test.tsx` (+2): re-reads on its own record's hint without the loading state, and keeps the rail when the live read fails.
- `frontend/src/features/records/paper-view/DocumentsTab.test.tsx` (+1): a file someone else added appears after the hint.

**Evidence:**

  - `DocumentsTab`, `ReviewTimeline` and `CommentsSection` passed together (81 tests).
- **Not run locally:** the backend tests (they need Postgres; CI is the record).
