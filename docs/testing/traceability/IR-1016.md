# IR-1016: Read the IRIS server's logs without SSH, through Session Manager

**Requirements:** no FR- id. Epic IR-805 (S2 Epic: Deployment). On 2026-11-10 (IR-806), every diagnosis needed SSH and `docker compose logs`.

## Decision (Hermoine Zozobrado, 2026-11-11)

**Session Manager replaces CloudWatch Logs as this ticket's scope.**

- Session Manager is free, opens no port and needs no key. It covers the everyday need: reading a service's logs from the console.
- CloudWatch Logs is pay-as-you-go past its 5 GB monthly free allowance, and is deferred. Its plan is kept on the Jira card.
- What this gives up:
  - searchable logs in the console;
  - logs that stay readable while the server is stopped or broken.

## What changed

- `deploy/README.md`, **Session Manager on a server built by hand:**
  - create a role with only `AmazonSSMManagedInstanceCore`;
  - attach it with no restart;
  - or add the policy to the role the server already has.
- `deploy/README.md`, **Read the logs:**
  - `docker compose ... ps` and `logs --tail` / `-f` / `--since`;
  - the service names;
  - the note that these logs live on the server only.
- A server made by `deploy/aws/iris-demo.yaml` already has the role (IR-1013), so it needs no change.
- No code change and no port opened.

## Evidence

- **Real account, `iris-demo`, `ap-southeast-1`, 2026-11-11, checked in the console by Hermoine Zozobrado:**
  - The role `iris-demo-ssm` (only `AmazonSSMManagedInstanceCore`) is attached to the instance.
  - The first Session Manager connection failed: the agent was "unable to acquire credentials" because it had started before the role was attached. `sudo snap restart amazon-ssm-agent` over SSH fixed it, and the README now says so.
  - A Session Manager shell opened from the console as `ssm-user`.
  - After `sudo -iu ubuntu` and `cd ~/IRIS`, `docker compose -f docker-compose.prod.yml logs --tail 20 frontend` showed the sign-in made just before. Run from the shell's starting folder instead, compose reports the file as invalid, which is why the README starts with those two commands.
