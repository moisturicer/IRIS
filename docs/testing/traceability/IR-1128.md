## IR-1128

**Requirement:** Every page the paper reader shows carries a faint "CIT-U" and the signed-in reader's name, without getting in the way of reading, selecting, finding, highlighting or a screen reader

**Design:** Jira IR-1128; ADR-048 decision 1, as amended 2026-11-15

**Implementation:** `frontend/src/features/records/paper-view/ReaderWatermark.tsx`, mounted by `PdfPageView` in `PaperPdfReader.tsx` over the canvas and text layer and under highlights, citations and review marks. An SVG path draws the download copy's letters (`apps/records/watermark.py`: same stroke, gap, grey, opacity and angle); a line below reads "Viewed by <name> (<email>) via CIT-U IRIS". The layer is `aria-hidden`, `pointer-events: none` and `user-select: none`. Nothing changes on the server

**Test:** `frontend/src/features/records/paper-view/PaperPdfReader.test.tsx`, "the reader's watermark": the reader is named on every page; the layer is hidden from assistive technology, takes no pointer events and cannot be selected; the text layer holds only the paper's text; axe finds no serious or critical violation

**Evidence:**

- 2026-11-15, locally: the four new tests pass, and the whole `PaperPdfReader.test.tsx` passes (78 tests).
- 2026-11-15, locally: the overlay's SVG, rendered in headless Chrome over a page of text, draws the same "CIT-U" as a downloaded copy, with the text beneath readable.
- Printing was **not** tested by a person yet. There is no print stylesheet, so a browser print renders the pages as shown, overlay included; pages outside the reader's live window print blank, as before this change.
