## ADR-035 §2 · §4 · §8 · §10

**Requirement:** **The provider can carry a tool-calling decision, exercised offline** — no FR- id; [ADR-035](../../adr/035-ask-iris-decides-whether-it-needs-evidence.md) (**Accepted** 2026-10-06; supersedes ADR-028's decision). IR-465 under [IR-456](https://citiris.atlassian.net/browse/IR-456)

**Design:** ADR-035 §2 (native tool calling, chosen for option value **against IR-462's own recommendation**; one no-parameter `search_corpus` tool; every malformed shape routes to evidence with its own code; arguments never read) · §3 (every doubt routes to retrieval) · §4 (a tool call is a route signal, never executed) · §8 (the call sees no Passage, recalled Turn or assistant answer text) · §10 (a hypothetical direct answer is measured for length and discarded)

**Implementation:** `apps/ai/providers/tool_calling.py` — `ToolCallingLLM`, **abstract with no default body**, so a decorator cannot silently bypass it; `ToolCompletion` carries text, reasoning, raw `ToolCall`s and token counts; the port is `(system, user, tools)` with no tool-result turn, because nothing executes · implemented **explicitly** by `OpenAICompatibleAdapter`, `RetryingLLMProvider`, `CircuitBreakingLLMProvider`, `FallbackLLMProvider` and `CompletionLoggingLLMProvider` (every class on the `answer` chain) and by `ScriptedToolCallingLLM`; a decorator over a text-only provider raises `TypeError` rather than falling back to `generate` · `generate`/`stream` offer no tool · `apps/ai/evidence/model_decision.py` — `ModelEvidenceDecision.decide(question, resolved_question, prior_reader_questions)` has **no parameter that could carry retrieved text**; eight fallback reason codes (`empty_completion`, `several_calls`, `text_and_tool_call`, `unknown_tool`, `malformed_arguments`, `timeout`, `rate_limited`, `provider_failure`) plus `search_requested`/`answered_directly`; only a non-blank text answer with no call routes direct; `ModelDecision` has no field that can hold model text; an unexpected exception propagates instead of becoming a silent fallback · `eval_evidence --model-decision` and `ModelResult` report the model alone, decided-only, the union, detector/model agreement, reason codes, anomalies, latency and tokens in a section **separate** from the detector's. **No per-call reasoning override and no fifth Inference task**, as ADR-035 §2 decided from IR-462's data

**Test:** `providers/tests/test_tool_calling.py` (21 — abstract method, schema and both turns on the wire, timeout forwarded, `generate`/`stream` send no `tools`, calls read back raw, empty completion returned not raised) · `resilience/tests/test_llm_tool_calling.py` (15 — retry, circuit and model-fallback behave as for `generate`; a text-only inner provider is refused) · `inference/tests/test_tool_calling_chain.py` (5 — **walks the real `answer` chain** and asserts every class implements the method itself; the completion record names the model and never the text) · `evidence/tests/test_model_decision.py` (55 — each fallback with its own code, precedence, **arguments never read** and absent from the result, request carries no passage/answer, hypothetical answer and reasoning absent from the result, repr, JSON and logs) · `evaluation/tests/test_evidence_model_report.py` (15) · `tests/test_eval_evidence_model_command.py` (6 — no `Conversation`/`Turn`, no answer text in console or file, refused when no model or a text-only provider)

**Evidence:** 117 new tests pass. `pytest apps/ai apps/tests` — **1874 collected, 1870 passed, 4 failed**; the 4 are the same host-`.env` failures recorded under IR-464 (`test_profiles.py`, `test_llm_contracts.py`), **re-verified failing identically on a clean `main`**. `flake8 apps/ai` clean. The existing HTTP suite is unmodified and passes. **No live vendor call was made**: the adapter is exercised against an injected client, so `search_corpus` against Groq and the `--model-decision` numbers are **not measured**
