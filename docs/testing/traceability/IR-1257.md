# IR-1257: Ask IRIS's conversation search box shows at rest

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** the search box above a person's conversations in Ask IRIS can be seen as a box before it is hovered. Reported by Hermoine Zozobrado on 2026-11-21. No FR- id.

**Cause, confirmed in the code first:** the box's `<label>` used the conversation links' style, `NAV_ITEM` in `ConversationSidebar.tsx`. That style has no background at rest, only `hover:bg-stone-200/70`, and `focus-within:bg-stone-200/70` while typing. The pane behind it is `bg-stone-50`, so until the pointer was on the box only its magnifier and placeholder showed.

## What changed

- `ConversationSidebar.tsx`: the search box has its own style, `SEARCH_BOX`. It is `bg-stone-100` at rest, does not change on hover, and is `bg-stone-200` while typing, which is how it shows focus. `NAV_ITEM` had no other user, so it is removed. The conversation rows have their own style and are unchanged.
- **No search box in IRIS changes colour on hover.** Checked on 2026-11-21: Discover, My submissions, a Saved folder, Find in this paper, Calls & Conferences, Guidelines and Users all mark only focus, with a border or a ring. This box was the only one with a hover fill.
