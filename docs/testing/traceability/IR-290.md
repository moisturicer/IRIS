## IR-290

**Requirement:** **Formulas recovered as LaTeX** — extends FR-M3-01 (stable label only, per the frozen-SRS rule)

**Design:** [ADR-025](../../adr/025-figures-and-formulas-in-extraction.md)

**Implementation:** `apps/ai/chunking/document.py` declares `FORMULA` as an element kind; `apps/ai/extraction/docling_mapping.py` maps Docling's `formula` label onto it instead of letting it survive by accident of the unknown-label rule; `apps/ai/extraction/docling_client.py` turns on `do_formula_enrichment` so an equation is meant to return as LaTeX rather than the text layer's mangled glyphs. A formula with no recoverable text is dropped, same as any other empty element — fails closed rather than storing garbled text as the author's notation.

**Test:** `apps/ai/extraction/tests/test_docling_mapping.py`, `apps/ai/extraction/tests/test_docling_client.py`

**Evidence:** `pytest apps/ai/extraction` green

**Status:** **PARTIAL** — enrichment is requested, `FORMULA` is a declared kind, and the mapping and drop-on-empty behaviour are tested against literal payloads. Two things are unverified because no live docling-serve instance or formula-heavy document is available in this environment: that Docling actually returns LaTeX with `do_formula_enrichment` on (the mapping tests only prove the mapper does not mangle whatever text arrives), and the extraction-time measurement against the 900s ceiling from IR-249. The ticket's own verification path — `inspect_chunks` on a Record with equations — is blocked on the same gap
