# IR-1261: My Library rows open their record when clicked

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** for simpler navigation, a click anywhere on a My Library row opens it, without a separate *Continue draft* or *Open review* button, and a draft's Delete moves somewhere less prominent in the row. Requested by Lee Jasmin Adolfo on 2026-11-21, who chose Delete in a "⋯" menu (option A) from a clickable prototype. No FR- id.

> **Superseded in part by [IR-1279](IR-1279.md) (2026-11-23):** a draft's row has the red trash can again, under *Updated*, and no "⋯" menu. The rest of this change (the row is the link, no *Continue draft* or *Open review*) stands.

**Design:** this supersedes [IR-1256](IR-1256.md)'s red trash can beside *Continue draft*; its dialog is unchanged, so [ADR-009](../../adr/009-authorization-model.md) decision 6 still holds: a draft is deleted only after one confirmation. It narrows [IR-1084](IR-1084.md)'s row actions to the acts that answer a request.

## What changed

- **The row is the link** (`SubmissionRow.tsx`): the title's link was already stretched over the row and, since [IR-1258](IR-1258.md), already led where the row's button did. A draft opens Publish over the page it is on (`publishHref`, e.g. `/records/mine?section=research&publish=<id>`); anything else opens Paper View (`/records/<id>`). With the row the link, the button beside it was a second way to the same place.
- **Removed:** *Continue draft* and *Open review*. **Kept:** each open request's act (the Overview still shows only the first) and *Continue as Thesis / Project*, which do something specific rather than open the record. A row with neither no longer draws an empty action strip.
- **Delete draft** (`DeleteDraft.tsx`): the trash can is replaced by the shared `RowMenu` ("⋯", IR-1077), named "Actions for “<title>”", with *Delete draft* as its danger item. It opens the same `ConfirmDialog`. On desktop it sits under *Updated* beside the chevron; on a narrow screen, where the chevron is hidden, it is pinned to the row's top corner and the text keeps clear of it, so the row does not grow.
- **Smoke dialog scan** (`e2e/smoke/support/dialogs.ts`): *delete a draft* opens the dialog through the row menu (`fromRowMenu`) instead of a button.
