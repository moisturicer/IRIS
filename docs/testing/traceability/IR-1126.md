# IR-1126 — Describe Figures with Unstructured's image-description enrichment

**Affected requirement labels:** none change status. It changes who could write a Figure's retrieval-only description, not what a reader sees.

[Back to the matrix](../TRACEABILITY.md)

**Outcome:** measured worse on quality and retrieval, so the switch stays off and `describe_figure` stays the describer. Evidence: `docs/evaluation/runs/2026-11-15-ir1126-image-descriptions/` (proxy tier, ADR-023). Data path: ADR-067, amendment 2026-11-15.

**Implementation:** behind `UNSTRUCTURED_IMAGE_DESCRIPTIONS`, default `False`.

- **Request.** With the switch on, `UnstructuredExtractor` adds `IMAGE_DESCRIPTION_OPTIONS` to the partition form, and provenance records it. **The spike showed the partition endpoint ignores it**, so on this endpoint the switch has no effect. With it off, the form is exactly `REQUEST_OPTIONS`.
- **Field.** The enrichment (Jobs API only) puts JSON in an Image element's `text`, with `type`, `description` and `texts`, plus `data` for graphs. Confirmed on six real papers. With the switch on, `_figures` reads `description` from that JSON onto `FigureImage.description`, joined by `element_id`. `texts` and `data` are not stored.
- **Storage.** `replace_figures` writes it to `ExtractionFigure.description`. No migration is needed.
- **Describer skipped.** `describe_figures` sends only Figures with an empty description. `with_descriptions` and the chunker treat a stored description as before: in `text`, never in `content`.
- **Second copy.** The raw element list, Image JSON included, stays in admin-only `PdfExtraction.raw_result`.
- **Trial reads** use the same settings.

**Tests:** `apps/ai/extraction/tests/test_unstructured_image_descriptions.py` covers:
- switch off: the form and the Figure are unchanged;
- switch on: the form and provenance carry the field, the description joins its Figure and is absent from every element's text;
- five unusable JSON shapes;
- setting wiring.

`apps/documents/tests/test_unstructured_figure_enrichment.py` covers:
- storage;
- the describer skipped when the switch is on and called when it is off;
- the description in chunk `text` and never in `content`.

**Evidence:** 2026-11-15, Windows 11, private test database `test_iris_ir1126`, `AI_RESEARCH_LANE=off AI_JEV_ROUTING_ENABLED=False`: the two new files, 13 passed. The full suite runs in CI.

**Status:** Implemented and measured, and left off. Reviewer sign-off on the quality verdicts is pending.
