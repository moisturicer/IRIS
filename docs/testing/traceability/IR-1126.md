# IR-1126 — Describe Figures with Unstructured's image-description enrichment

**Affected requirement labels:** none change status. It changes who writes a Figure's retrieval-only description, not what a reader sees.

[Back to the matrix](../TRACEABILITY.md)

**Implementation:** behind `UNSTRUCTURED_IMAGE_DESCRIPTIONS`, default `False`.

- **Request.** With the switch on, `UnstructuredExtractor` adds `IMAGE_DESCRIPTION_OPTIONS` (`advanced_options` = `{"enrichments": {"image_description": {}}}`) to the partition form, and the read's provenance records it. With it off the form is exactly `REQUEST_OPTIONS`.
- **Field.** Unstructured's docs put the enrichment in the Image element's `text`, as a JSON string with `type` and `description`. With the switch on, `_figures` reads `description` from that JSON onto `FigureImage.description`, joined to its Figure by `element_id`. Text that is not JSON, or has no usable `description`, leaves it empty. Shaping already blanks Image text, so the JSON never reaches `content`.
- **Storage.** `replace_figures` writes it to `ExtractionFigure.description`. No migration: IR-852 added the column.
- **Describer skipped.** `describe_figures` already sends only Figures with an empty description, so an enriched Figure is never sent to `describe_figure`. `with_descriptions` puts it on the element and the chunker appends it to `text`, never `content`, exactly as for a described Figure.

**Tests:** `apps/ai/extraction/tests/test_unstructured_image_descriptions.py` (off: form and Figure unchanged; on: form and provenance carry the enrichment, the description joins its Figure and is absent from every element's text, five unusable shapes leave it empty; the setting drives the adapter). `apps/documents/tests/test_unstructured_figure_enrichment.py` (on: stored, describer sends nothing; off: stored empty, describer sends it; the chunk's `text` carries it and no `content` does).

**Evidence:** 2026-11-15, Windows 11 host, private test database `test_iris_ir1126`, `AI_RESEARCH_LANE=off AI_JEV_ROUTING_ENABLED=False`: the two new files, 13 passed. The full suite is left to CI.
