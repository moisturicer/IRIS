# IR-1126 — Describe Figures with Unstructured's image-description enrichment

**Affected requirement labels:** none. Nothing changes in the product; Figures are still described by `describe_figure` (IR-852).

[Back to the matrix](../TRACEABILITY.md)

**Outcome:** measured, found worse on quality and retrieval, and **not adopted**. Evidence: `docs/evaluation/runs/2026-11-15-ir1126-image-descriptions/` (proxy tier, ADR-023). Data path: ADR-067, amendment 2026-11-15.

**No code ships.** A switch (`UNSTRUCTURED_IMAGE_DESCRIPTIONS`) that stored the enrichment's description on each Figure and skipped `describe_figure` for it was built, tested (13 tests passing), then removed by decision of Jive Tyler Revalde on 2026-11-15. The partition endpoint IRIS uses ignores the request, so the switch could never take effect. A Jobs-API reader would be needed first, and the measurement gives no reason to build one.
