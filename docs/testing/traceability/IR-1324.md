# IR-1324: My Library's tabs, reorganised

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** the layout of My Library's tabs, as Hermoine Zozobrado asked for on 2026-11-24. It was agreed in chat before any code was written. There is no FR- id.

- **Tab names** are Title Case, and the current tab is a filled maroon pill.
- **The search field** has no outline until it has focus.
- **My Submissions:**
  - a long search bar;
  - the five filters as underlined words, every one always shown, with no counts;
  - each group under a plain heading, with nothing folded.
- **Saved Papers:**
  - the Folder dropdown is replaced by grey folder tiles that show each folder's name and paper count;
  - a **+ Folder** button names a new folder in a pop-up;
  - each tile's "⋯" menu has *Rename* (a pop-up) and *Delete folder*;
  - closing a pop-up just closes it, with no warning;
  - the reading filters are shown as underlined words;
  - each empty state has a plain message, for no saved papers and for no folders.
- **Saved Calls:** a search bar, and a plain message when there are no saved calls.
- **Overview:**
  - *Continue reading* is gone;
  - *Waiting on you* has no maroon outline; it is drawn like *Recently opened*;
  - each waiting paper has one small *Submit documents* link.

**Design:** frontend only. Every list comes from the same server reads as before.

## What changed

- `LibraryToolbar.tsx` (new):
  - `LibrarySearch`, the one search field;
  - `UnderlineFilters`, a group of toggle buttons on a ruled line. It replaces `FilterChips.tsx`, now deleted.
- `MyResearchList.tsx`:
  - all five filters show, and an empty one names what it would hold;
  - groups are `section`s with plain headings, where they used to be `details`.
- `ReadingPanel.tsx`: `FolderShelf` replaces `FolderPicker`. A long folder name wraps in full; the Full Text Rule allows no cut there.
  - It shows folder tiles, named `"<folder>, <n> papers"`, plus a History tile.
  - **+ Folder** opens a *New folder* dialog. It's disabled at the limit, with a line saying why.
  - Each tile has a "⋯" menu (`RowMenu`) with *Rename*, which opens a *Rename folder* dialog, and *Delete folder*. The folder view no longer has these buttons.
  - Closing either dialog by Cancel, ×, Escape or a click outside just closes it. Nothing asks first and nothing is saved.
  - With no folders, a dashed tile shows instead.
  - A new folder appears as a tile. It used to open straight away.
- `SavedView.tsx`:
  - The search box takes the toolbar's free width, beside Sort and the layout switch, with no box around it.
  - The folder tiles and a *Papers* heading show above the reading filters.
  - A folder or History view has an *All saved papers* link back.
- `SavedCallsSection.tsx`:
  - a search by title or place;
  - *No saved calls right now* when nothing is saved, and a no-match message.
- `LibraryOverview.tsx`: the *Continue reading* card is removed. Each waiting paper has one *Submit documents* link; the requests' own words stay in its screen-reader name.
- `MyLibraryPage.tsx`: the Title Case tab names.
- `docs/ui-ux/01-design-system.md`: a *My Library tabs* row, which records the Title Case exception to DESIGN.md's sentence-case rule.
