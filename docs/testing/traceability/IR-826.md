## IR-826 — The AI gateway stops receiving DATABASE_URL, or ADR-014's precondition is amended

**Basis.** [ADR-014](../../adr/014-ai-gateway-as-a-service.md) precondition 4 (no direct database access) and its amendment of 2026-11-03. Gap found by IR-617 and IR-670.

**Done here.**

- `ai-gateway` no longer receives `DATABASE_URL` in `docker-compose.yml` or `docker-compose.prod.yml`. No code under `ai/` read it (`ai/infrastructure/settings.py` declares no such field, and `extra="ignore"` drops unknown keys). It handed Django's login to a service on the `egress` network. The Compose comment names this ticket, not IR-58, which Jira doesn't have.
- ADR-014's amendment is **accepted** (Jive Tyler I. Revalde, 2026-11-04). Running AI services hold `iris_ai_runtime` only, for AI-owned runs (IR-722, IR-723) and research tools (IR-719).
- `ai/.env.example` no longer lists the maintenance login, and `ai/runs/config.py` refuses runs on a service that has it set.

**Parity.** The amendment names `apps/ai/tests/test_research_read_policy_db.py` (IR-718) as what holds the row policy to `visible_to(user)`.

**Tests.** `backend/apps/tests/test_gateway_database_access.py` (6, reads files): the gateway's active lines in both Compose files, and `ai-runs-worker`'s in `docker-compose.yml`, carry no `DATABASE_URL` or `DB_USER`/`DB_PASSWORD`/`DB_NAME`, and the gateway's block names IR-826 and not IR-58. The first version ran red before the Compose change (4 failed) and green after. After review the worker case was added; the five Compose-reading test files then passed together, alongside `test_traceability_shape.py`. Run locally with throwaway settings values; the worktree has no `backend/.env`.

**Also tested.** `ai/tests/test_runs_config.py` refuses runs with the maintenance login set, and `test_gateway_database_access.py` fails if `ai/.env.example` lists it as an active setting.

**Not run.** `docker compose config`: no repo-root `.env` in this worktree. CI's Compose job checks it.

**Evidence.** [PR #498](https://github.com/moisturicer/IRIS/pull/498).

**Status:** **VERIFIED** — both acceptance criteria met; review pending.
