# IR-1325: The Overview's side cards are one height

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** on My Library's Overview, *Waiting on you* and *Recently opened* are the same height, and that height is shorter than *Waiting on you* was (28 rem). Hermoine Zozobrado asked for this on 2026-11-24, after [IR-1324](IR-1324.md). There is no FR- id.

**Design:** frontend only.
- `LibraryOverview.tsx` gives both cards one constant, `SIDE_CARD_HEIGHT` (`h-96`, 24 rem).
- *Waiting on you* shrinks from 28 rem, and *Recently opened* grows from 20 rem.
- Each list still scrolls inside its card.

## Tests

**IMPLEMENTED.** Run locally on 2026-11-24:
- `npm run test:changed --maxWorkers=2`: 367 passed, 3 skipped.
- `npm run lint` and `tsc` are clean.
- **Screenshot:** the Overview at 1280 px on a production build, with both cards full enough to scroll. Measured: both cards are 384 px tall.

No test was added. The tests read the page through its accessible tree, which has no heights, so the screenshot is the evidence here. CI and a person's review are still to come.
