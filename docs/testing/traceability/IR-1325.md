# IR-1325: My Library tweaks, and document requests that go with *Finish review*

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** Hermoine Zozobrado asked for this on 2026-11-24, after [IR-1324](IR-1324.md). The design was agreed in chat. There is no FR- id. [ADR-022](../../adr/022-explicit-document-requests.md) Amendment 9 (Accepted 2026-11-24, PR #1010) holds the document-request decision.

- **My Library:**
  - *Waiting on you* and *Recently opened* are one height (24 rem).
  - A faint rule sits under the tabs.
  - Folder tiles are narrower.
  - With no folders, Saved Papers shows a framed *No folders yet* empty state.
  - ADR-044's 2026-11-24 amendment is marked Accepted.
- **Document requests:**
  - A reviewer asks for documents only in the Documents tab.
  - Each request is a draft that only they see. They can remove it until it's sent.
  - *Finish review*'s *Request changes* or *Comment only* sends it.
  - Every other verdict is refused while any wait.
  - *Request changes* carries no documents and always asks for a new version.
- **Documents tab:**
  - Once a paper is submitted, the owner gets *Upload* only on what was asked for.
  - Download and Upload are drawn smaller.
  - There are no Open buttons: a version's title, or an attachment's name, opens it.

## Design

**Server.**
- `DocumentRequestState.DRAFT`, with migration `documents/0030`. Its SQL is a no-op (`sqlmigrate` prints `-- (no-op)`), so no stored row changes.
- `requests.create_request(draft=True)` writes no audit event and sends no notification.
- `requests_for(record, viewer)` hides other people's drafts. `request_on_visible_record` answers someone else's draft with 404.
- `PATCH /document-requests/<id>/` deletes a draft (204).
- `finish_review` sends the caller's drafts for the Seat's party (`requests.send_drafts`), or refuses any other verdict while drafts wait. It no longer reads `documents` or `new_version`.
- `removal.discard_drafts` deletes draft requests along with draft comments.

**Screens.**
- `RequestChangesFields.tsx` is deleted.
- `FinishReviewDialog` lists the drafted requests it sends, and holds the other verdicts with the server's reason.
- `ReviewerDocumentRequests` marks drafts *Not sent yet* and gives each a *Remove* link.
- `RequestDocumentDialog`'s button reads *Add to review*.
- `DocumentsTab`:
  - *Upload* appears only on a requested slot, or on every slot while the paper is a draft.
  - A version's title, or an attachment's name, opens it.
  - Download and Upload use `SMALL_ACTION_TARGET`/`SMALL_ACTION_PILL`: a 28 px pill in a 44/36 px target.
