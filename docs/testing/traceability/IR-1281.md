# IR-1281: The sign-in page has no Help in its header

[Back to the matrix](../TRACEABILITY.md)

**Requirement:** remove *Help* from the sign-in page. Requested by Hermoine Zozobrado on 2026-11-23. No FR- id.

**Design:** no ADR change.

## What changed

- `LoginPage.tsx` no longer passes `help` to `EntryFrame`, so `/login`'s header shows only the IRIS and CIT-U logos, with no link.
- What Help offered is still on the sign-in form: *Forgot password?* (`LoginForm.tsx`) and *Create an account*.
- Register (`/signup`) keeps its Help, since the request named sign in only. `EntryFrame`'s `help` prop stays for it. *(IR-1352 later removed Help from Register too, and with it the prop.)*
