# IR-1102 — Formulas as exact LaTeX: crop each hi_res Formula and transcribe it, behind a flag

**Affected requirement labels:** none change status. Part of IR-980; implements ADR-067's amendment of 2026-11-14 (exact LaTeX for formulas) and its IR-1102 implementation note.

[Back to the matrix](../TRACEABILITY.md)

**Implementation:**

- **Inference task.** `transcribe_formula` joins the closed set beside `describe_figure`, with its own Profile (`LLM_TRANSCRIBE_FORMULA_*`, off until a model is set), the `ingestion` admission lane and `DataPolicy.NO_TRAINING` (requests deny data collection; retention accepted, decided 2026-11-14). `CompositionRoot.formula_transcriber()` is its only caller; `test_reserved_task.py` was changed deliberately to guard both vision tasks.
- **Cropping.** At a Manuscript read, each shaped `Formula` is rendered from the stored PDF at 300 dpi by `apps/documents/pdf_evidence/crops.py`, a sandbox child like the PDF evidence reader, under the same `PDF_EVIDENCE_*` limits; Linux only. A Formula `hi_res` already returns as delimited LaTeX is cropped too. Each crop is stored as an `ExtractionFormula` (migration `documents/0024`). A superseded revision's formulas are removed with its Figures. The task's time limit holds a second evidence wall for the crops; `test_extraction_failures.py` was changed deliberately to say so.
- **Transcribing.** `apps/ai/formula_transcriptions.py` runs as `transcribe_extraction_formulas`, queued after a read that stored crops. The gate and revision are re-read before every send; each call goes through ADR-041 admission. The reply is JSON: LaTeX and one description line. LaTeX, description, `\tag` equation number, the model that replied (a fallback included) and the request are stored on the row. An unavailable call is retried; a refused admission stops the rest; a refusal or unreadable reply is recorded once and leaves the crop, never the OCR text. Any transcription re-chunks the paper.
- **Readers see the LaTeX.** `with_formulas` puts each transcribed formula at its place; the labeled chunker shows it as `$$…$$` in `content`, flag on or off, which the answer model reads and the reader UI renders with KaTeX. The description is never shown.
- **Search, off by default.** `AI_FORMULA_TEXT_INDEXED` is the chunking option `index_formulas` (recorded with every chunk set and settable on a trial variant). On, the LaTeX and description enter the embedded text and the keyword index; off, neither does. The keyword index reads the new `DocumentChunk.keyword_text` (migration `ai/0048`, which replaces the trigger), null except where a transcribed formula is, so no other chunk's index changes. Every `eval_retrieval` run file records the switch as `formula_text`; a run cannot move it.
- **Reranking** drops passages with no `content` before the call: Voyage refuses an empty document, and an uncaptioned Unstructured Figure chunks to none. Found while measuring.

**Tests:** `apps/documents/tests/test_formula_crops.py` (shaping keeps no OCR; targets and boxes, LaTeX-typed formulas included; 300 dpi render size; a bad box does not stop the rest; sandbox output read only as PNGs; Linux sandbox end to end; crops stored at extraction and transcription queued; a trial variant sets `index_formulas`). `apps/ai/tests/test_formula_transcriptions.py` (reply parsing; one record per formula with every field; the fallback that replied is stored; unavailable call owed and retried; refusal recorded once, no OCR in any chunk; refused admission; gate refusal; unset Profile; stale revision; off, readers see the LaTeX and nothing of it is embedded or keyword-indexed; on, both are, at the formula's place; a chunk with no formula is indexed by its content). `apps/ai/tests/test_eval_formula_transcription.py`, `apps/ai/retrieval/tests/test_reranking.py` (empty content never sent), `test_profiles.py`, `test_reserved_task.py`, `test_techniques.py`, `test_fixed_workflow_fixture.py` (the proxy audit re-pinned deliberately).

**Evidence:** 2026-11-14, Windows 11 host.
- New and changed test files, plus the chunking, repository, trial, keyword index, figure description and shaping suites, all pass locally (1 Linux-only skip). The full suite is left to CI on the PR.
- Migrations `documents/0024` and `ai/0048` applied to `iris_ir1102`, a copy of the dev database, as well as to empty test databases.
- `docs/evaluation/runs/2026-11-14-ir1102-formulas/`: Sonnet 5.5 transcribed 36 of 36 proxy formulas; 32 exact after normalization, 35 typeset like the source read by hand, 0 mathematical errors (spike: 34 of 36). Retrieval over 16 formula questions (`proxy_formulas.json`, also appended to `proxy_starter.json` as kind `formula`): recall@10 0.812 off and 0.938 on without reranking, 0.938 in both arms with reranking. Default stays off.
