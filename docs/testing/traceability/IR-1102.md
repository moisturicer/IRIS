# IR-1102 — Formulas as exact LaTeX: crop each hi_res Formula and transcribe it, behind a flag

**Affected requirement labels:** none change status. Part of IR-980; implements ADR-067's amendment of 2026-11-14 (exact LaTeX for formulas).

[Back to the matrix](../TRACEABILITY.md)

**Implementation:**

- **Inference task.** `transcribe_formula` joins the closed set beside `describe_figure`, with its own Profile (`LLM_TRANSCRIBE_FORMULA_*`, off until a model is set), the `ingestion` admission lane and `DataPolicy.ZERO_RETENTION`. `CompositionRoot.formula_transcriber()` is its only caller; `test_reserved_task.py` was changed deliberately to guard both vision tasks.
- **Cropping.** At a Manuscript read, each shaped `Formula` (an image element with no text; shaping never keeps the OCR) is rendered from the stored PDF at 300 dpi by `apps/documents/pdf_evidence/crops.py`, a sandbox child like the PDF evidence reader, under the same `PDF_EVIDENCE_*` limits. Linux only. Each crop is stored as an `ExtractionFormula` (migration `documents/0024`): name, page, box, image. A superseded revision's formulas are removed with its Figures. The task's time limit now holds a second evidence wall for the crops; `test_extraction_failures.py` was changed deliberately to say so.
- **Transcribing.** `apps/ai/formula_transcriptions.py` runs as `transcribe_extraction_formulas`, queued after a read that stored crops. The gate and revision are re-read before every send, and each call goes through ADR-041 admission. The reply is JSON: LaTeX and one description line. LaTeX, description, `\tag` equation number, the model that replied (a fallback included) and the request are stored on the row. An unavailable call is retried; a refused admission stops the rest; a refusal or unreadable reply is recorded once and leaves the crop, never the OCR text.
- **Indexing, off by default.** With `AI_FORMULA_TEXT_INDEXED` on, `with_formulas` turns each transcribed formula into a formula element at its place. The labeled chunker embeds its LaTeX and description, and shows `$$LaTeX$$` with the description below, which is what the keyword index reads. Off, chunks are unchanged. The switch is `formula_text` in every `eval_retrieval` run file; a run cannot move it, since it acts at indexing.

**Tests:** `apps/documents/tests/test_formula_crops.py` (shaping keeps no OCR; targets and their boxes; 300 dpi render size; a bad box does not stop the rest; sandbox output read only as PNGs; Linux sandbox end to end; crops stored at extraction and transcription queued). `apps/ai/tests/test_formula_transcriptions.py` (reply parsing; one stored record per formula with every field; the fallback that replied is the stored model; unavailable call owed and retried; refusal recorded once, no OCR in any chunk; refused admission; gate refusal; unset Profile; stale revision; flag off leaves chunks unchanged; flag on embeds and keyword-indexes at the formula's place). `test_profiles.py`, `test_reserved_task.py`, `test_techniques.py`.

**Evidence:** 2026-11-14, Windows 11 host, local test database: the new and changed test files only, 99 passed, 1 skipped (the Linux sandbox test). The full suite is left to CI on the PR. flake8 clean on the changed files. Migration `documents/0024` was applied only to an empty test database.

**Not done:**

- No formula questions were added to the proxy question set, and no `eval_retrieval` run comparing formulas in and out is committed. Both need the proxy corpus re-read through Unstructured and paid Voyage calls.
- Transcription was not scored against `formulas/latex_truth.py`: that needs paid Sonnet 5.5 calls on the four proxy papers. No model was called.
- **Open condition:** the transcription provider's retention and no-training terms must be recorded before real Manuscripts are sent.
- No endpoint serves a formula crop, so an untranscribed formula shows nothing to a reader.
- A Formula hi_res already returns as delimited LaTeX is kept as that text and not cropped; past 500 formulas per Manuscript the rest are not cropped; the equation number is only what the model's `\tag{}` says.
