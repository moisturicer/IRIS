## IR-585

**Requirement:** **Move the remaining hand-rolled selects onto the `Select` primitive and mark required fields one way** — no FR- id; subtask of IR-898 (forms). Touches NFR-A1. Follows IR-539, whose "(required)" criterion it deliberately supersedes (decided 2026-10-14, comment on IR-585)

**Design:** Jira IR-585 (decisions comment of 2026-10-14) · [`../ui-ux/01-design-system.md`](../../ui-ux/01-design-system.md) "Marking fields" · [`../ui-ux/12-accessibility.md`](../../ui-ux/12-accessibility.md)

**Implementation:** The app marks the optional field and never the required one. `components/ui/FieldLabel.tsx` takes `optional` and writes "(optional)" inside the `<label>`, so it is part of the accessible name; `Input` and `Select` take `required` (`aria-required` only, nothing visible) or `optional`, and the `FieldMarker` type refuses both. `Select` gains `sm` and `inline` for the library toolbar. Selects move onto `Select` in `UserListPage`, `AuditLogPage`, `RequestDocumentDialog`, `SavedView`, `ReadingPanel`, `OpportunityFormDialog`, `MetadataForm` (three) and `AssignReviewerDialog`; `AdviserCombobox` stays a combobox and gains `required`. `MetadataForm` marks Field of research and PSCED optional and puts `aria-required` on Title, Abstract, Year, Adviser and the author entry; its asterisk is gone. Register's markers are gone and it shows none, because IR-857 had already removed its middle initial. Not moved: Paper View's Add reviewer, Route and Version pickers and `ReassignDialog`, which move when next touched

**Test:** `components/ui/Select.test.tsx` and `Input.test.tsx` (required announces and writes nothing; optional is in the name; neither marks nothing) · `features/records/metadata/MetadataForm.test.tsx` (3) · `features/opportunities/CallsAndConferencesPage.test.tsx` (the dialog's required and optional fields) · `features/auth/SignupPage.test.tsx` (one test changed deliberately: no visible marker where it asserted "(required)") · the existing page tests and their axe checks for the user list, audit log, call board, edit details and publish are unchanged and pass

**Evidence:** 2026-11-05: `tsc --noEmit` clean, eslint with no new warning, `npm run test:changed` 52 files / 1031 tests passed; after the review the affected folders (ui, metadata, opportunities, library, audit, accounts, review, document-requests, auth, publish, edit details) ran 32 files / 563 tests, all passing once the new Year assertion used `spinbutton`. Full suite left to CI. Not checked in a browser: the library toolbar's inline label and the Folder select, which no longer tints when a folder is chosen. Known gap: `Select` `sm` is 36 px, below `12-accessibility.md` §4's 44 px, as the old toolbar selects were
